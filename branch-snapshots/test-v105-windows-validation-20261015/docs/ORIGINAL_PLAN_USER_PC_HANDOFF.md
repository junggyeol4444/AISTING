# 원본 기획안 실기기 확인 인계 — 개발 중단 사유 아님

기준 문서는 `docs/ORIGINAL_PLAN.txt` 7부입니다. 사용자에게 개발 작업을 떠넘기지 않습니다.
개발자가 접근할 수 없는 **사용자 PC의 실제 모델·아바타·스피커·방송 계정** 확인만 따로 구분합니다.
확인 요청이 완료되기 전에도 소스 개발은 계속합니다. 미확인 기능은 완료로 표시하지 않습니다.

## 원본 1단계: Open-LLM-VTuber 실제 실행

실제 설치·모델 준비는 소유자 승인 없이 하지 않습니다. 기존 공식 프로젝트가 준비되어 있다면
AISTING 저장소 루트에서 다음 명령으로 **공식 서버**를 실행할 수 있습니다.

```powershell
python scripts/launch_original_stage1.py --project-dir "C:\path\to\Open-LLM-VTuber"
```

기본 실행 후 공식 화면 `http://localhost:12393`에 접속합니다.
공식 프로젝트 자체에서 실제 AI 대화를 실행하고 **한국어 답변, 실제 음성 출력,
Live2D 아바타가 말하는 장면**을 확인해야 합니다. 이것들이 작동하지 않으면 1단계 미통과입니다.
사용자에게 인계할 정보는 성공 여부 또는 **오류 문구와 화면 한 장**이면 충분합니다.
환경이 없다면 '실제 프로그램 미설치'라고 알려주시면 되며, 이 경우에도 소스 개발은 계속합니다.
AISTING의 Tkinter 샘플과 모의 답변은 원본 1단계 검증에 사용하지 않습니다.

## 원본 2단계: 권리를 확보한 한국어 목소리

이 기능의 소스 개발은 1단계 사용자 PC 검증이 없어도 계속합니다.
권리가 확보된 음성 자료의 선택·모델 학습과 실제 합성은 해당 자료를 소유한 사용자의 승인 및 실행이 필요합니다.
공식 GPT-SoVITS 설치/학습 절차를 따르고, 이미 만들어진 참조 음성 파일이 있으면
다음 명령으로 공식 Open-LLM-VTuber의 설정 변경 내용을 먼저 볼 수 있습니다.

```powershell
python scripts/configure_original_stage2.py --project-dir "C:\path\to\Open-LLM-VTuber" --reference-audio "C:\path\to\licensed.wav" --reference-text "음성 파일에 실제 녹음된 문장"
```

위 명령은 **설정을 수정하지 않습니다**. 출력된 변경 내용을 확인하고 직접 승인할 때만
끝에 `--apply`를 붙여 다시 실행합니다. 그러면 기존 `conf.yaml` 백업을 별도로 만들고
원본 Open-LLM-VTuber의 공식 GPT-SoVITS 엔진·한국어 음성 설정 및
AISTING에 확정 저장된 캐릭터 이름/말투/성격을 적용합니다.

2단계 합격은 **GPT-SoVITS가 실제로 해당 캐릭터 목소리로 한국어를 발화하고,
공식 아바타의 입이 따라 움직이는 것**으로 확인합니다.
서버 연결·문서/설정 검사는 실제 음성 성공의 대용이 아닙니다.
현재 사용자 PC에서 실제 합성 및 립싱크는 **미검증**입니다.

## 이후 개발의 진행 원칙

3단계는 실제 OBS 송출 + 플랫폼 채팅/아바타/음성 연결, 4단계는 실제 종료 자동화,
5단계는 실제 예약 시작 및 무인 사이클입니다. 그 뒤 원본 기획안의 공지, 장시간
운영, 선택적 게임 순서로 이어집니다. 실제 송출·외부 게시·계정 연결은 각 실행 전에
별도 사용자 승인 없이 시도하지 않습니다.

**사용자 PC 검증 미실시 ≠ 개발 작업 중단. 구현과 실기기 통과 여부를 분리해 보고합니다.**
