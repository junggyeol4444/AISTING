# AISTING v17 Windows PC 실제 확인 인계 (실행 전 승인 필요)

원본 프로그램이 아닌 **검증된 별도 로컬 사본**에서만 작업. 기존 사용자 데이터와 설정은 사전 백업하고 원본 EXE는 보존. 프로그램 설치·모델 다운로드·방송·재생·외부 게시 금지 상태로 먼저 확인한다.

1. 별도 사본에 패치를 적용한 후 기존 앱 실행. 캐릭터를 `캐릭터 확정·저장`으로 한 번 저장하고 앱을 완전히 종료한 다음 재실행한다. **합격:** 저장한 이름·말투·성격이 복원됨.
2. 캐릭터 편집란에 **미저장 초안**을 입력하되 `캐릭터 확정·저장`은 누르지 않고 `방송 설정 저장 (캐릭터 제외)`만 누른다. 앱을 종료·재실행한다. **합격:** 초안이 확정되지 않으며 이전 확정 캐릭터가 유지됨.
3. 방송 설정 중 콘텐츠를 하나 변경하여 저장한다. **합격:** 콘텐츠 변경은 유지되고 확정 캐릭터는 변경되지 않음.
4. (가능할 때) 서로 다른 두 앱 창에서 A 창을 열어 둔 상태로 B 창에서 캐릭터를 확정한다. A 창에서 방송 설정만 저장한다. **합격:** B에서 확정한 캐릭터가 사라지지 않음. B에서 방송 설정까지 변경한 경우 A의 저장은 충돌 오류를 표시하고 기존 파일을 유지해야 함.
5. `settings.json.before-broadcast-*.bak` 및 `settings.json.before-character-*.bak` 백업과 수정 전·후 설정 파일의 SHA-256을 로컬에서 비교한다. **합격:** 백업은 변경 전 파일과 바이트 일치, 민감 설정은 외부 전송 없음.

오류 수집: 날짜/시간, 누른 버튼 순서, 오류 대화상자 문구, 프로그램 콘솔/오류 로그, `settings.json`의 **키 목록만**(값·API 키·개인정보 제외), 원본/사본 파일 SHA-256을 기록한다. API 키, 음성 파일, 캐릭터 비공개 설정 원문은 공유하지 않는다. 이 검사는 실제 AI 대화·GPT-SoVITS 음성·Live2D·OBS 방송 검증이 아니다.
