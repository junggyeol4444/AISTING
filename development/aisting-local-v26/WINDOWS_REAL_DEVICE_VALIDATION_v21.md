# AISTING v21 향후 실제 PC 검증 항목 — 지금은 개발만 진행

1. 사용자 직접 승인 후 공식 Open-LLM-VTuber 서버를 준비한다. 서버 `conf.yaml`의 LLM 제공자와 비용·네트워크 사용 여부를 사용자가 확인한다.
2. 기존 프로그램의 **방송인 홈 → 1단계 · 실제 AI 텍스트 대화**를 선택하고 질문을 넣어 매 질문마다 명시 승인한다.
3. 합격 조건(미검증): 공식 서버에서 `set-model-and-conf` 초기화와 진짜 `audio.display_text.text` 문장, 그리고 `control.conversation-chain-end`를 순서대로 수신해 창에 실제 응답이 나타나며 가짜 문장이 나오지 않는다.
4. 이 창은 받은 음성 데이터를 재생하지 않고 OBS로 전달하지 않는다. 실제 한국어 TTS, Live2D 아바타 입 움직임, OBS, 플랫폼 채팅은 별도 동작 증거로 확인한다.
5. 실패 시: 정확한 조작, 시간, 상태 메시지, 개인 정보와 API 키를 삭제한 공식 코어 오류 로그, 서버/모델 버전을 수집한다. 원본 파일·저장된 캐릭터를 수정하는 재현은 하지 않는다.

이 검증은 본 회차에서 실시하지 않았다.
