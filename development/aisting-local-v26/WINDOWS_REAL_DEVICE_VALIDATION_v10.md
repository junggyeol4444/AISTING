# 사용자 PC 실기기 검증 인계 — AISTING 기존 프로그램 v10 수정안

**아직 실행하지 않은 검증 계획**이다. 이 문서는 프로그램 설치, 모델 다운로드/학습, 음성 재생, 방송 송출, 계정 로그인, 외부 게시에 대한 승인이 아니다. 실제 실행/재생/송출은 각 작업에 대해 사용자가 별도로 명시 승인할 때만 진행한다. 수정 패키지는 아직 기존 전체 원본에 적용되지 않았으며 Windows EXE도 없다.

## 먼저 완료해야 하는 개발자 작업

기존 AISTING 전체 원본의 읽기 전용 스냅샷 확보 → 별도 사본 생성 → v10 패치 적용 → 원본 기능/설정/기억/100단계 기록 보존 확인 → Windows EXE 별도 경로 빌드. 이 단계가 끝나지 않으면 아래 사용자 실기기 검증을 요청하지 않는다.

## 1단계 실제 AI·Live2D 검증 (사용자가 실행 승인한 경우에만)

1. 기존 PC에 이미 준비된 **공식 Open-LLM-VTuber** 설치 폴더를 선택하고, 기존 설정 파일과 프런트엔드 존재 여부를 읽기 전용으로 검사한다. 실제 실행 전에는 설정 동기화/네트워크/모델 다운로드 가능성을 별도로 확인하고 승인받는다.
2. 사용자 승인 후 공식 서버와 공식 Live2D 화면을 실행한다. `127.0.0.1:12393`의 HTTP 200 및 `/client-ws`의 `set-model-and-conf` 수신은 **연결 증거**일 뿐 실제 AI/아바타 작동 증거가 아니다.
3. 실제 LLM이 사용자의 한국어 질문에 **새로운 한국어 답변**을 생성하는지, 선택한 실제 Live2D 모델이 화면에서 움직이는지 사용자가 관찰한다. 마이크/스피커 사용은 별도 승인 후에만 허용한다.
4. **합격 기준:** 실제 모델 이름/설정 이름 확인 + 실제 한국어 질문에 대한 실시간 LLM 생성 답변 + Live2D 화면에서 모델의 실제 움직임을 관찰한 기록. 셋 중 하나라도 없으면 1단계 미검증으로 유지한다.

## 2단계 실제 한국어 GPT-SoVITS 검증 (사용자가 학습/재생을 별도로 승인한 경우에만)

1. 본인/동의/라이선스 권리가 확보된 기존 WAV/FLAC과 그 파일에 실제로 말한 문장을 선택한다. v10에서 WAV/FLAC 컨테이너 헤더와 로컬 API 주소를 확인한다. 이 검사는 음질/권리/언어/음성 모델 호환성 검증이 아니다.
2. 실제 GPT-SoVITS 서버가 사용자의 PC에 **이미 준비된 경우**, 사용자 승인 후 공식 코어 `conf.yaml`에 선택한 로컬 주소·참조 파일·문구를 백업 후 기록한다. v10은 TTS 서버를 설치하거나 모델을 학습하지 않는다.
3. **합격 기준:** 사용자가 승인한 실제 한국어 문장이 GPT-SoVITS 엔진에서 실제 음성으로 합성되어, 사용자가 허용한 재생 환경에서 확인되고 Live2D 입 움직임과 함께 관찰되어야 한다. 단순 설정 저장, 헤더 검사, HTTP 연결, 무음 테스트는 합격 증거가 아니다.

## 3단계 OBS·플랫폼 채팅 검증 (별도 방송 승인 전에는 송출 금지)

1. 설치되어 있는 OBS WebSocket에 사용자 승인 후 로컬 접속해 실제 버전/장면/소스/스트림 상태를 읽는다. 소스 목록 존재는 실제 화면·오디오 전달의 증거가 아니다.
2. 플랫폼 실시간 채팅 연결 코드가 완성된 이후 사용자 지정 비공개 방송에서만 실제 메시지 수신/전부 반응·화면·음성 전달을 별도로 검증한다. 방송 시작, 로그인, 게시/공지에는 각각 명시 승인 필요.
3. **합격 기준:** 실제 플랫폼 채팅 메시지의 원문·수신 시각·실제 AI 반응·OBS 출력 영상/음성 기록이 대응되어야 한다. 현재는 이 검증을 수행할 단계가 아니다.

## 오류 수집 방법과 민감정보 보호

실행 실패 시 **사용자가 승인한 테스트 시각**, Windows 버전, 실행한 기존 EXE 경로, 화면에 보이는 오류 문구, 관련 로컬 프로그램 로그의 오류 부분(앞뒤 20줄 정도), 공식 서버 종료 코드, OBS 버전/장면 상태를 기록한다. 실제 음성/영상 기록은 사용자의 별도 동의가 있어야만 남긴다. `conf.yaml` 원문이나 API 키·토큰·계정 비밀번호·스트림 키·개인 대화·음성 원본 파일은 인계 파일에 포함하지 않는다. 로그 공유 전 민감정보를 지운다.

이 계획은 실제 검증을 완료했다는 주장이 아니다. 실제 검증 대기 중에도 별도 로컬 코드 개발은 계속한다.
