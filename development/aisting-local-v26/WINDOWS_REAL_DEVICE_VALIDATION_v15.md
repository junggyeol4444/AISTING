# AISTING v15 — Windows 실기기 확인 인계 (미실행)

**실기기에서 아직 검증하지 않았습니다.** 이 문서는 승인 없는 설치·모델 다운로드·음성 재생·방송·로그인·외부 게시를 허용하지 않습니다.

기존 AISTING 전체 소스와 사용자 설정·기억·100단계 기록은 원본에 그대로 두고, `prepare_local_source_copy.py --source <원본> --destination <새_사본>`으로 읽기 전용 미리보기를 확인합니다. 사본 생성은 별도 승인 후 `--copy`로만 수행하고, `apply_to_existing_aisting.py --source <사본>`으로 읽기 전용 패치 검토를 합니다. 승인된 사본에만 `--apply`를 사용합니다. 마지막으로 `audit_local_patch_preservation.py --source <사본>`으로 모든 기존 파일·폴더 보존을 확인합니다.

## 캐릭터 확인 (외부 방송 영향 없음)

1. 사용자 PC의 **기존 설정을 유지한 사본**에서 프로그램을 실행하고, 전용 **캐릭터 확정 저장**으로 이름·말투·성격을 확정한 뒤 종료/재실행합니다. 기존 원본 설정을 덮어쓰지 않는 별도 환경에서만 테스트해야 합니다.
2. 재실행 시 스튜디오의 **저장된 캐릭터**에 동일한 값이 자동 복원되는지 확인합니다. 일반 **방송 설정 저장**만으로 캐릭터가 확정되거나 미저장 초안이 적용되면 불합격입니다.
3. 이미 준비된 공식 Open-LLM-VTuber 폴더를 지정하고 **확정 캐릭터 ↔ 공식 conf.yaml 비교 (읽기 전용)**를 누릅니다. 비교만으로 `conf.yaml`의 내용·수정시각·백업 개수가 바뀌면 불합격입니다.
4. 불일치가 표시되어도 자동 적용되면 불합격입니다. 사용자가 별도로 승인하여 공식 설정에 적용한 후 비교를 다시 실행했을 때 일치가 표시되는지 확인합니다.
5. 일치 판정은 **디스크의 설정 파일만** 의미합니다. 실제 LLM 답변에 말투/성격이 반영되는지, 실제 GPT-SoVITS 한국어 음성과 Live2D 움직임이 나오는지는 원본 7부 1~2단계에 따라 별도 사용자 승인 후 실기기에서 검증해야 합니다.

**오류 수집:** 단계, Windows/Python 버전, 실행 명령, 종료 코드, 비교 화면의 오류 문구, 개인정보를 가린 콘솔 로그, `conf.yaml` 파일 크기·SHA-256(내용 제외), 변경 전후 파일 개수만 수집합니다. API 키·음성·캐릭터 설정 원문·기억 DB·토큰·비밀번호는 공유하지 않습니다. 실제 OBS 송출/채팅/공지/스케줄러는 이 검증에 포함하지 않습니다.
