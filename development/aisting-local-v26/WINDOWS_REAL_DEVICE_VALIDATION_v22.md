# AISTING v22 향후 PC 실기기 확인 (현재는 미실시)

1. 기존 AISTING 프로그램 안전한 사본에 v22를 적용한 이후, 운영자가 별도 승인한 공식 Open-LLM-VTuber 서버만 직접 실행하고 LLM 공급자/결제/네트워크 설정을 확인한다.
2. 방송인 홈 → 「실제 AI 텍스트 대화」에서 한 창으로 두 번 질문한다. 질문마다 승인한다.
3. 합격 조건: 같은 서버 WebSocket 연결을 두 턴에 재사용하며, 각각의 공식 응답을 순서대로 텍스트로 누적 표시하고 대화 문맥이 실제 코어에서 유지되는지 사용자가 판단한다. 재접속 후 새 세션에서는 문맥 연속을 보장하지 않는다는 표시가 있어야 한다.
4. 음성·아바타·OBS 송출·플랫폼 채팅·스케줄러는 이 검사만으로 합격하지 않는다. 음성 자동 재생/실제 송출은 없다.
5. 실패 시 공식 서버 버전, 사용자 PC OS, 질문 시각, 동작 순서, 개인정보/API 키를 지운 오류 로그, 화면의 연결/세션 상태를 수집한다.

이번 회차에는 이 실기기 검증을 실행하지 않았다.
