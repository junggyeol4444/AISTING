# AISTING 기존 프로그램 로컬 수정 패키지 v6 — 2026-10-15

## 이번 회차에서 실제로 한 일

v5의 기존 소스 개조 방식을 그대로 보존하고, **기존 원본 전체 소스를 안전하게 별도 로컬 사본으로 옮겨서 패치할 수 있는 준비 절차**를 추가했다. 새 AISTING 프로젝트를 만들지 않았고, GitHub 쓰기·설치·모델 다운로드·학습·계정 인증·실제 송출·외부 게시를 실행하지 않았다.

- `prepare_local_source_copy.py` 신규: **기본은 읽기 전용 검사**. `--source`로 지정한 기존 전체 AISTING 폴더에서 `desktop.py`, 원본 기획안, 100단계 기록, 실행 진입점, 요구사항/상태 문서를 확인하고, `desktop.py` Git blob SHA를 검증한다. 심볼릭 링크·특수 파일을 거부한다. `--copy`를 명시해야만 이미 존재하지 않는 별도 로컬 목적지에 전체 프로그램 파일과 설정/데이터를 사본화한다. `.git` 메타데이터만 제외한다. 원본과 사본의 **모든 일반 파일** SHA-256을 비교하고 복사 도중 원본 변경도 감지한다. 복사본 최상위 폴더 권한을 제한하고 무결성 근거 파일을 만든다. 오류 시 부분 사본을 폐기한다. 사용자 원본은 변경하지 않는다.
- `apply_to_existing_aisting.py` 개선: 패치 대상 코드 디렉터리의 심볼릭 링크를 거부한다. 기존 `desktop.py` 백업을 **생성 순간부터 권한 0600**으로 만들고 `fsync` 및 원본 바이트 검증 후에만 패치 작업을 계속한다. 교체 임시 파일도 `fsync` 한다. 원본 SHA 검사, 수동 `--apply`, 새 모듈 충돌 거부, 실패 시 신규 모듈 삭제는 유지한다.
- `tests/test_v6_existing_source_preservation.py` 신규: **인위적으로 만든 소스 파일 시스템 픽스처**에서 읽기 전용 미변경, 원본 데이터·100단계 기록 복제, `.git` 제외, 링크 차단, 데이터 복제 손상 감지 및 폐기, 사본에만 패치 적용과 비공개 백업, 패치 교체 실패 시 원본 유지와 신규 모듈 롤백을 확인했다. 이 픽스처는 실제 전체 AISTING 프로그램이 아니며 실제 기능 검증을 뜻하지 않는다.

## 검증 기록과 한계

- 현재 실행환경 `/mnt/data`에 v5 ZIP 실재 확인, 압축 검사 성공, 로컬 작업 공간에 추출.
- GitHub 연결 도구로 `main`의 `src/ai_broadcaster/desktop.py`를 **읽기 전용** 조회한 Git blob SHA가 `a5df12a74a27a5a50657da9c968253859b98b8ed`와 일치함을 확인.
- 로컬에서 기존 v5 테스트 28개와 v6 파일 보존 테스트 6개, **총 34개 보조 단위/계약 테스트 통과**. Python 구문 검사 통과.
- `git ls-remote` 방식의 GitHub 직접 네트워크 조회는 실행환경 DNS 차단으로 실패. GitHub 읽기 커넥터는 파일별 조회가 되지만 **전체 main 소스가 로컬에 확보된 것은 아님**.
- 따라서 기존 전체 `desktop.py`에 v6 패치를 실제 적용하거나, 실제 사용자 설정/기억 복원·100단계 기능 회귀·Windows EXE 빌드·AI/TTS/Live2D/OBS/채팅/스케줄러의 실제 작동을 검증하지 못했다.

## 향후 실제 전체 원본을 확보했을 때의 순서

1. 기존 원본 소스 디렉터리를 변경하지 않고 `python prepare_local_source_copy.py --source <기존소스> --destination <새_로컬_사본>`으로 읽기 전용 확인.
2. 소스가 확인되고 사용자 승인된 별도 로컬 사본 생성이 필요한 경우에만 위 명령에 `--copy` 추가. 기존 폴더 내부에 사본 생성 금지.
3. 사본을 대상으로 `python apply_to_existing_aisting.py --source <새_로컬_사본>`으로 읽기 전용 확인, 이후 **사용자 승인한 로컬 사본에만** `--apply`.
4. 기존 사용자 설정/기억/100단계 기록 무결성, 캐릭터 확정 저장/재실행 복원/초안 격리, 공식 AI/TTS/Live2D/OBS 코드 통합 회귀 검증.
5. Windows 실제 EXE, 공식 코어 실제 한국어 AI·음성·Live2D, GPT-SoVITS, 실제 플랫폼 채팅+OBS, 종료·시작 자동화, 공지, 장시간 운영 순으로 계속 개발. 외부 실행은 별도 승인.

**v6 패치 및 사본 보존 로컬 검사 작업 구간은 끝났다. 전체 AISTING 프로젝트는 미완성이다.**
