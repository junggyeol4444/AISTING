**기준:** 이미 있는 AISTING의 `src/ai_broadcaster/desktop.py`와 전체 기존 기능을 보존하는 수정 패키지입니다. 새 프로젝트가 아닙니다. GitHub의 `main`과 테스트 브랜치에는 이번 작업으로 아무것도 쓰지 않았습니다.

## 이번에 실제로 수정한 코드

- **원본 기획안 1단계 / 공식 Open-LLM-VTuber:** 포트가 단순히 열려 있는지만 검사하던 경로를 고정된 `127.0.0.1:12393`의 **실제 HTTP GET /** 응답 검사로 교체했습니다. 성공한 HTTP 응답만으로 AI 대화, Live2D, 음성 구현 여부를 추정하지 않습니다. 서버를 실행한 뒤 중간에 종료돼도 종료 코드와 기존 로그 경로를 표시합니다. 사용자가 확인 버튼을 눌렀을 때만 **이 앱이 직접 시작한 공식 서버 프로세스**를 종료할 수 있고, OBS나 다른 프로세스는 종료하지 않습니다.
- **원본 기획안 2단계 / GPT-SoVITS:** 기존 공식 프로젝트 `conf.yaml`의 백업 및 설정을 수정할 때, 파일에 포함될 수 있는 API 비밀키가 백업으로 유출되지 않도록 백업 파일을 생성하는 순간부터 소유자 전용 권한을 사용합니다. 원본 설정 파일 권한도 보존합니다. 임의 음성 생성/학습/재생은 하지 않습니다.
- **원본 기획안 3단계 / OBS:** 실제 OBS WebSocket에 접속하면 현재 장면·송출 여부에 더하여 **해당 장면의 화면 소스 및 OBS 입력 소스 목록**을 실제 읽기 요청으로 조회하도록 추가했습니다. 장면/입력 목록의 존재는 실제 영상·TTS 소리가 송출된 증거가 아닙니다. 연결 성공·실패 결과가 열려 있는 확인 창에도 표시되며, 중복 연결 요청과 창 닫힘 후 잘못된 UI 갱신을 처리합니다.

## 적용 방법

기존 프로그램 원본 소스가 들어 있는 폴더(최초 GitHub main 소스와 일치하는 버전)가 별도로 필요합니다. ZIP을 풀고 기존 원본 폴더에 대해 다음 작업을 수행합니다.

```powershell
# 수정 가능성 검사만 수행, 실제 파일은 수정하지 않음
python apply_to_existing_aisting.py --source "D:\AISTING"
# 사용자가 확인한 경우에만 기존 desktop.py 백업 및 원본 수정
python apply_to_existing_aisting.py --source "D:\AISTING" --apply
# 기존 Python, Tkinter, PyInstaller가 설치돼 있을 때만 별도 EXE 빌드
.\build_existing_windows.ps1 -ExistingProject "D:\AISTING"
```

**주의:** 소유자의 실제 기존 프로젝트 사본에만 적용하세요. 원본 `desktop.py` Git blob SHA는 `a5df12a74a27a5a50657da9c968253859b98b8ed`이어야 합니다. 다르면 자동으로 거부하며 이전 작업을 덮어쓰지 않습니다. 이번 ZIP은 원본 전체 프로그램이나 즉시 실행 가능한 Windows EXE가 아니고 **기존 코드 수정 패키지**입니다.

## 사용자 PC 검증 인계

실제 공식 프로그램의 AI 대화·음성·아바타 움직임은 사용자 PC에서 확인해야 합니다. 오류가 나는 경우 프로그램이 표시한 오류 문구나 로그를 전달하면 됩니다. 이 확인을 기다리느라 개발을 중지하지 않으며, 확인 전에는 완료 판정도 하지 않습니다. 플랫폼 방송 송출 및 외부 게시, 설치·다운로드는 별도의 사용자 승인 없이는 실행하지 않습니다.
