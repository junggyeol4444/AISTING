# AISTING 기존 프로그램 단계별 개발 계획 — v26

이 문서는 기존 `docs/ORIGINAL_PLAN.txt` 1~8부 및 7부의 실제 **0~8단계**를 기준으로 하는 *개발 진행 문서*이며, 기존 `config/roadmap.json` **100단계 기록을 수정하거나 대체하지 않습니다**. 실제 검증 결과가 없으면 단계 완료라고 표시하지 않습니다. 사용자가 승인하지 않은 프로그램 설치/모델·플러그인 다운로드/훈련/로그인/녹음/스피커/OBS 송출/외부 게시/원본 사용자 파일 변경/저장소 쓰기는 하지 않습니다.

## 0단계 — 운영자 선택 및 권리 정리
- 원문 기준 플랫폼, 방송 콘셉트·콘텐츠, 캐릭터, 목소리 권리/허가, 서버, 직접/외주 선택 사항을 사용자가 결정한다.
- 현 상태: **일부 미결정**. 도구가 임의 설정이나 유료 서비스를 선택하지 않는다.

## 1단계 — 공식 Open-LLM-VTuber를 이용한 실제 로컬 AI·기본 음성·Live2D
- **1A 개발 중(v26)**: 실시간 스트리밍 문장 표시, 오류 시 미완료 응답 표시, 음성 이벤트 크기 알림 추가.
- **1A 기존**: 기존 AISTING 데스크톱 GUI에 공식 서버 선택/실행 전 외부 영향 점검, WebSocket 세션 유지, 승인 후 `text-input` 송신 및 `audio.display_text` 실제 응답 표시.
- **v23 기존**: 공식 `audio` 응답의 WAV 구조 수신/유효/무효/무음 분류 및 실제 데이터 수신량 표시. 음성 데이터 수신은 음질/한국어 발음/아바타 립싱크 증거가 아니다. 오디오 재생·저장 없음.
- **1B 부분 개발(v25)**: 설치된 공식 model_dict.json/Cubism 참조 파일 점검 → 사용자 명시 선택 → 백업 후 conf.yaml 단일 아바타 키 수정. 실제 Open-LLM-VTuber WS 초기화의 모델 정보는 AI 대화 결과에 표시. **미완료**: 실제 Live2D 프런트엔드 렌더링과 AI/TTS 동기화, 실행 중 서버 설정 전환 증거 및 Windows 내장 표시.
- **1B 추가 개발(v25)**: 이미 설치된 공식 Live2D 프런트엔드의 기존 로컬 HTML 응답 확인 및 운영자 승인 후 실제 공식 웹 렌더러 열기. HTML 전송 확인은 아바타 렌더/음성 동기화의 증거가 아니며, AISTING 텍스트 대화와 공식 프런트엔드는 별도 세션일 수 있음. **미완료:** 두 창의 같은 세션 통합·내장 WebGL 렌더링.
- **1C 추후 실기기 판정**: 실제 한국어 질문/대화 맥락, 음성 청취, Live2D 입/표정 연동을 사용자 PC에서 확인하며 사용자가 최종 판단.

## 2단계 — 실제 한국어 GPT-SoVITS
- 현재 기존 GPT-SoVITS `conf.yaml` 설정 보존·승인 UI 코드 일부 구현. 한국어 실제 모델/합성/음색 검증 **미완료**.
- 합법적으로 사용 가능한 음성 파일과 모델 준비/학습은 사용자가 별도 승인해야 하며 이 환경에서 실행하지 않는다.

## 3단계 — 실제 플랫폼 채팅과 OBS 비공개 방송
- 현재 OBS 로컬 상태 조회/장면 제어 준비 코드 일부 구현. **실제 플랫폼 채팅 수신·전부 AI 전달/응답, OBS 오디오/영상 결합·비공개 실제 송출 미완료**.
- 방송 플랫폼은 사용자 선택을 따른다. 모든 채팅을 읽고 반응하도록 설계하며 임의 메시지 선별·인위적 지연을 추가하지 않는다.

## 4단계 — 자연스러운 마무리 및 OBS 자동 종료
- 사용자 지정 종료 조건 → 실제 AI 마무리 발화 → 음성/화면 동기화 → 종료 OBS 제어. **미완료**.

## 5단계 — 무인 시작~종료 스케줄러
- 사용자 지정 시간 및 정책으로만 기동/종료. 장애 중복 송출 방지. **미완료**.

- 기존 `src/ai_broadcaster/desktop.py` 및 `offline_settings.py`, 원본 기획 1~8부, `config/roadmap.json` 100단계와 모든 기존 사용자 데이터/기억 보존이 최우선.
