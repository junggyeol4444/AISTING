# v26 Windows 실기기 검증 안내 — **지금 실행하지 않아도 됨**

사용자가 실기기 검증을 이후로 미루도록 지시했으므로 이 문서는 나중에 참고할 안내입니다. `v26`은 전체 기존 프로그램에 아직 통합하지 못한 소스 수정 패키지이며 실행 가능한 EXE가 아닙니다.

추후 운영자가 설치한 공식 Open-LLM-VTuber가 준비됐고, 모든 외부 연결·LLM 요금·음성권리·TTS 실행 영향을 이해한 상태에서만 별도 승인 후 실행합니다. 테스트에 사용자의 기존 데이터 폴더를 직접 쓰지 말고 사본을 사용합니다.

## 확인 절차
1. 기존 프로그램 사본을 실행하고 `공식 AI 실제 대화`를 엽니다. 승인 전에는 공식 서버에 질문을 보내지 않았는지 확인합니다.
2. 승인 후 본인 소유의 일반 한국어 질문을 하나 입력합니다. 각 문장이 실제 공식 서버에서 도착할 때마다 **같은 창에 순차적으로 표시**되는지 관찰합니다. 기다림이 발생하면 임의 응답을 표시하면 안 됩니다.
3. 같은 연결에서 두 번째 질문을 전송하고 문맥 유지 여부를 사용자 기준으로 판단합니다. 서버 오류/연결 단절 시 이전 세션의 기억을 보장한다고 표시해서는 안 됩니다.
4. 도중 종료/연결 오류라면 받은 문장에 **부분 응답(미완료)** 경고가 있는지 확인합니다. 정상 완료 후 같은 문장이 중복 출력되지 않는지 확인합니다.
5. 음성 데이터 수신량은 표시할 수 있으나 스피커 재생이나 Live2D 립싱크는 수행/검증하지 않았음을 확인합니다. 공식 브라우저 프런트엔드는 아직 별도 세션이라는 경고도 확인합니다.

## 합격 기준 및 오류 수집
- 실제 서버에서 보낸 두 개 이상의 문장 조각이 수신 순서로 표시되고, 완료 시 한 번만 나타남.
- 승인 취소 시 질문이 전송되지 않음. 오류/닫힌 창의 결과가 새로운 대화 창에 나타나지 않음.
- 문제가 발생하면 날짜, 실행 버전, 표시 오류 문구, 공식 서버의 개인정보를 제거한 로그, 단계별 재현 방법, 오류 발생 직전 사용자 승인 여부를 수집. API 키, 계정 정보, 실제 대화 원문 및 모델 음성 파일은 무단 공유 금지.
