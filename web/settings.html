AI 방송인 설정

고른 내용은 내 PC에만 저장해. 설정 저장이 방송 송출, 결제, API 연결을 시작하지는 않아.

1. 방송 플랫폼 — 원하는 곳을 복수 선택

선택하지 않으면 '나중에 결정' 상태로 저장돼. 아직 방송은 시작되지 않아.

3. AI 캐릭터

4. 목소리

음성 복제나 음성 파일 수집은 여기서 하지 않아. 사용 권리 확인 후 따로 승인해야 해.

5. 아바타

유료 모델·프로그램 구매는 하지 않아. 무료로 사용 가능한 자료만 검토해.
