# AISTING — AI 방송인 프로젝트

원본 기획안을 기준으로 **100개 개발 단계**를 추적하는 저장소입니다.

## 현재 단계
- 완료: 1단계(목표 정리), 2단계(핵심 기능 정의)
- 다음: 3단계(방송 플랫폼 결정, **운영자 선택 필요**)
- 원본 요구사항: docs/ORIGINAL_PLAN.txt
- 진행 현황: docs/STATUS.md

## 실행
Python 3.11 이상에서 외부 패키지 없이 실행 가능합니다.

```bash
python tools.py validate
python tools.py status
python -m unittest discover -s tests -v
```

## 정기 작업
`.github/workflows/hourly-development.yml`이 GitHub Actions에서 매시간 **30분(UTC 시각, 한국도 매시간 30분)**에 실행되도록 설정됩니다.
현재 예약 워크플로는 요구사항/테스트 검증, 실행 보고서 작성 및 다음 단계 개발 Issue 생성을 합니다. **AI가 알아서 코드를 작성하는 기능은 아직 없습니다.** 자동 AI 개발에는 별도 에이전트/인증과 비용·안전 설정이 필요합니다.

## 개발 지침
- 사용자가 채팅에서 개발을 지시하면 예약 실행을 기다리지 않고 여기 저장소를 수정합니다.
- 사용자가 PC를 껐더라도 GitHub Actions는 독립적으로 실행됩니다. PC 상태 자체는 감지하지 않습니다.
- 설치, 결제, 계정 연동, 방송 송출, 공지 게시, 목소리 사용은 운영자 승인 없이는 하지 않습니다.
- 채팅을 일부러 누락하거나 답변을 인위적으로 늦추지 않습니다.
- 프로젝트 본체(실시간 방송 코어, TTS/OBS 연동 등)는 아직 구현되지 않았습니다.
