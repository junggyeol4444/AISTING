# AISTING — 로컬 Windows 프로그램 누적 개발본 v105 (사용자 관점 오프라인 안정성 유지보수)

**개발 방식: 이 대화에서 파일로만 전달.** GitHub·원격 저장소·자동 커밋·PR·병합은 사용하지 않습니다. 앱 자체에는 자동 개발 예약·방송 실행 기능이 없습니다. 사용자가 별도로 요청한 이 대화의 개발 예약은 앱 내부 예약과 다릅니다.

## 포함된 기능
- Windows `tkinter` 독립 프로그램 창 (웹사이트/브라우저 아님)
- 치지직·유튜브·트위치 **0~3개 자유 복수 선택**(사전 확정 요구 없음), 방송 콘셉트·캐릭터·목소리·2D/3D 선택 및 로컬 저장
- 실제 채팅 플랫폼이 아닌 **시청자 대본 연습**: FIFO, 중복 채팅도 전부 응답, 실패 시 보존/재시도
- 무료 **모의 응답** 기본, 선택적으로 내 PC에서 실행 중인 Ollama 모델을 이용한 텍스트 답변
- 로컬 SQLite 기억(선택적 AI 사용 시), 별도 2D 샘플 데모
- **새 기능 v02:** Windows PC에 이미 설치된 한국어 음성 조회/미리 듣기/중지, 마지막 AI 답변 수동 읽기, 기본 OFF인 자동 읽기 옵션
- **새 기능 v02:** 여러 채팅 답변의 음성 FIFO 처리, 음성 재생 중 2D 샘플 입 움직임
- **새 기능 v03:** 2D 캐릭터를 로컬 별도 운영체제 창에 표시, 남색/초록색 배경 선택, 본 창과 프레임 동기화, 중복 창 방지, 창별 안전한 닫기
- 외부 방송 송출, 계정 로그인, 결제, 음성 복제는 하지 않음

## Windows에서 실행
Python 3.11 이상이 이미 설치되어 있다면 `run_windows.bat` 더블클릭.
명령어 방식: `py -3 scripts\run_desktop.py`.

## .exe 빌드
**이 ZIP은 EXE 완성 파일이 아니라 프로그램 소스**입니다. Windows에서 PyInstaller가 이미 준비된 경우에만
`build_exe_windows.bat`를 실행하면 `dist\AISTING.exe` 생성.
PyInstaller가 없다면 자동 다운로드/설치를 **하지 않고 종료**합니다.
빌드가 가능한지 아직 실제 Windows 환경에서 검증하지 않았습니다.

## 테스트
`py -3 -m unittest discover -s tests -v`  또는 `python -m unittest discover -s tests -v`.
모의 서버/외부 라이브 방송 없이 실행할 수 있도록 테스트를 구성했습니다.
