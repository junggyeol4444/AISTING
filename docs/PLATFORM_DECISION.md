# 3단계 — 방송 플랫폼 결정 (운영자 선택 대기)

원본 기획안 7-1(0단계 준비)에 포함된 운영자 결정 사항이다.

- 후보: YouTube, 치지직, Twitch (기획안에 등장하는 플랫폼)
- **선택 결과: 없음**. 개발자가 대신 결정하지 않는다.
- 연동 계정, 스트림 키, 실제 방송 송출: 미설정·미실행.
- 선택된 플랫폼이 있어도 `operator_approved`와 `external_broadcast_enabled`가 명시적으로 참이어야 다음 단계 검토가 가능하다.
- 그 경우에도 실제 송출 어댑터가 구현되기 전에는 코드에서 실행을 거부한다.

구현 위치: `src/ai_broadcaster/platform_config.py`, `config/platform.json`.

3단계는 선택이 확정될 때까지 **미완료** 상태를 유지한다. 그 사이 공통 모의 실행 엔진은 개발해도 외부 계정/방송 플랫폼에 접근하지 않는다.
