# 로컬 SQLite 대화 기억 / 대화 맥락

무료 로컬 Ollama 어댑터에서 **이전 대화와 AI 답변을 기억하여** 다음 요청에 문맥으로 넣는다.
사용자 PC 전용 SQLite에 기록하며 클라우드 또는 GitHub에는 대화 기록을 올리지 않는다.
오류 또는 음성/출력 실패 시 기억은 저장하지 않는다. 실제로 출력된 뒤에만 저장한다.

- 저장 위치 (Windows): LOCALAPPDATA/AISTING/conversation_history.sqlite3
- 기본 문맥: 최근 8개 대화 쌍 (설정 가능: 0~40개)
- SQLite 저장 보관: 최근 5,000개 대화 쌍까지
- 같은 텍스트 채팅도 누락시키지 않음, 인위적 응답 지연 없음
- 프로그램 재시작 후에도 저장된 문맥 사용
- 운영자가 SQLite 기억을 삭제할 수 있음
- 로컬 모델이 없어도 가짜 로컬 서버로 자동 테스트

### 한계
SQLite에 남아 있는 짧은 대화 문맥 유지로, 방송 전 기간을 의미 검색하는
장기기억이나 관계 추론은 아직 구현되지 않았다. 마이크/TTS/OBS/실방송도 미구현.
실제 AI 모델 사용은 운영자 PC에서 로컬 모델을 준비한 후 **수동으로만** 가능하다.
예약 개발은 중지.
