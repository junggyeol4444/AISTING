## 실제 개발
1. `src/ai_broadcaster/approved_live_voice_outbox.py`: 이전 방송 세션별 **미시도 대기·시도/불명 건수**를 음성 원문 복호화 없이 조회. 운영자 직접 승인과 동일 방송 확인 두 조건이 모두 참이어야 이전 세션의 **대기 상태만** 새 세션에 SQLite `BEGIN IMMEDIATE` 단일 트랜잭션으로 이동. 현재 세션에 대기/시도가 있으면 FIFO 충돌 방지를 위해 거절. 과거 시도/불명은 절대 재시도하지 않는다. 인계 시 원래 세션 ID·새 세션 ID·순번 범위·건수를 별도 append-only SQLite 기록에 보존한다.
2. `src/ai_broadcaster/approved_live_voice_output.py`: 실제 Windows 방송용 음성 작업자에 운영자 선택 인계 연결. 현재 OBS WebSocket 실제 송출, 기존 `ApprovedVoiceStreamLease` 연속성, 공식 Live2D 창 캡처를 읽기 전용 확인한 뒤에만 인계. 방송/녹화/장면 변경·계정 인증·모델 학습 없음. 인계 성공 시 기존 FIFO 작업자만 깨움. **이전 OBS 출력 지문은 DB에 없으므로 앱이 과거·현재 방송의 동일성을 독립적으로 증명할 수 없고, 운영자의 명시적 확인이 필수**.
3. `src/ai_broadcaster/desktop_chat_tab.py`: Windows GUI에 과거 미발화 세션 목록·세션 ID 선택·동일 방송 확인 1/2·실제 음성 발화 최종 승인 2/2·백그라운드 OBS 확인/인계 결과 표시 연결. 버튼을 누르지 않으면 과거 발화는 자동으로 이동하지 않는다. GUI 세션이 변경되면 이전 결과를 새 세션에 표시하지 않는다.
