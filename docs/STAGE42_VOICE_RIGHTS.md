# AISTING cumulative v42 — original roadmap 041: 사용할 음성의 권리 및 동의 확인

## 범위 (새로운 동의 자동 부여 아님)

- 원본 `docs/ROADMAP_100.md`의 **041 '사용할 음성의 권리 및 동의 확인'**에 대한 사용자가 입력하는 로컬 점검 UI/기록 구현.
- `src/ai_broadcaster/voice_rights_review.py` 및 기존 Windows Tk `desktop.py`의 **'음성 권리·동의 확인'** 탭.
- 방송 설정의 기존 선택값 `미정/Windows 기본 설치/본인 목소리/동의받은 목소리/라이선스 확보 목소리` 중 **현재 선택한 음성 확보 방식**을 사용. 사용자의 플랫폼·콘텐츠·캐릭터·음성·아바타 선택을 변경하거나 자동 확정하지 않음.
- 운영자가 '음성 자료 사용권', 'AI 학습·복제 용도', '방송 이용', '권리 문서 직접 검토' 네 확인 항목과 짧은 메모를 직접 작성. 미리보기는 파일을 전혀 만들거나 읽지 않음.
- 수동 저장은 사용자의 확인 대화상자 뒤에만 전용 로컬 JSON `voice_rights_operator_review.json` 생성. `training_authorized=false`, `streaming_authorized=false`를 영구적으로 기록. 체크를 다 해도 **권리 자체 신고가 끝났다는 의미**이며 유효한 라이선스·법적 동의의 진위가 검증되거나 음성 학습/방송이 허가된 것이 아님.
- 저장 기록은 수동으로만 불러오며 **현재 선택한 음성 출처와 일치할 때만** 화면에 반영. 방송 설정에서 음성 출처를 바꾸면 직전 확인 체크와 메모 즉시 초기화. 수동 2회 확인 삭제. 다른 자료의 권리 확인을 재활용하지 않음.
- 메모는 **기밀/실명/원본 음성 파일 경로를 적지 말도록** UI에 안내. 메모 최대 240자, 줄바꿈/제어문자 거부. 메모는 로컬 평문이며 민감한 증빙 서류/음성 녹음 자체는 저장하지 않음.
- `Windows 기본 설치 음성` 및 `미정` 선택은 체크를 모두 채워도 녹음/음성 복제 대상의 권리 확인 준비 완료로 분류하지 않음. Windows TTS 라이선스/이용 조건 확인 역시 별도로 필요.
- 경로 링크/정션 검사, 크기 제한, JSON 스키마 검증, 임시 파일에 쓴 뒤 원자 교체, 삭제 확인 등을 사용.
- 설정 파일 `settings.json`, SQLite 기억, 저장된 금기/피드백 기록, 프로젝트 기획안, 원래 음성 선택 데이터는 코드에서 읽거나 변경하지 않음 (사용자가 다른 '방송 설정' 탭에서 하는 별도 작업 제외).
