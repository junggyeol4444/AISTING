# v52 / 원본 051 승인된 아바타 준비 — 오프라인 수동 초안

## 범위

원본 `docs/ROADMAP_100.md`의 051 "승인된 아바타 준비" 중, 사용자 PC·모델 파일 접근 없이 구현 가능한 **운영자 수동 메타데이터 및 사용권 점검표**만 개발했다. 기존 `미정 / 2D / 3D` 아바타 선택과 2D Tk 샘플을 그대로 사용한다. **정식 모델 준비 완료 또는 사용자 승인과 동일하지 않다.**

- 새 화면: `아바타 모델 준비표`. 현재 아바타 선택, 자료 출처(미정/직접 제작/제작 의뢰/라이선스 확보), 임의 별칭, 사용 권리/방송 화면 표시 범위/증빙의 세 가지 운영자 자체 체크, 선택 메모를 기록한다.
- 외부 파일 경로·URL 대신 별칭만 입력한다. 2D/3D 선택을 바꾸면 화면의 체크/별칭/메모 초기화. 이전 저장 기록을 다른 종류로 불러오지 못하게 한다.
- 저장 시 운영자의 명시적인 1회 확인, 삭제 시 2회 확인. `avatar_preparation_draft.json`만 별도 저장하고 기존 방송 설정·SQLite·캐릭터·음성·아바타 선택값은 변경하지 않는다.
- 저장 레코드에는 `model_file_accessed`, `license_verified`, `rendering_authorized`, `broadcast_authorized`, `pc_inspected`가 반드시 `false`. 외부에서 조작한 승격 레코드·크기 초과·링크 경로·잘못된 구조는 거부한다.
- 단순 체크 상태가 모두 채워져도 "운영자 자체 신고 체크 완료 · 실제 사용 승인 대기"라고 표시한다. 법적 권리의 진위는 확인하지 않는다.

## 완료했다고 주장할 수 없는 것

모델/소스의 권리 서류 진위, 실제 2D Live2D/3D VRM 파일 취득·열기·렌더링·구동, 설치, 실제 Windows PC 검증, 립싱크 및 방송에 사용 가능한 권리, 010 전체 개발 최종 사용자 승인은 **대기**. 사용자 허락 전 PC 데이터 수집·파일 자동 스캔·모델 다운로드·GitHub·네트워크·OBS 송출 없음.
