# v75 · 공식 074 음량 및 방송 화면 확인 — 오프라인 부분 구현

- **원본 로드맵 항목**: `074 음량 및 방송 화면 확인`.
- **코드 개발 도달 범위**: 74/100. 공식 로드맵 체크박스와 `config/roadmap.json`은 계속 `pending`(승인·실기기 검증 미완료).
- **범위**: 사용자가 선택한 로컬 **목표 음량 설정값(0~100)** 과 기존 640×360 Canvas **구성 태그** 점검. 실제 출력 음압(dB), 음질, 클리핑, 스피커·믹서·오디오 장치, 화면 픽셀/송출 화질, OBS/실제 방송/Windows 검증 **아님**.

## 구현

- 기존 `offline_settings.validate_voice_profile`의 0~100 음량 규칙을 유지하며 새 설정 필드나 영구 저장소를 만들지 않습니다. UI의 현재 음량값을 읽는 읽기 전용 명시적 검사이며 저장 명령은 없습니다.
- 새 `offline_broadcast_output_audit.audit_broadcast_output`: 현재 화면 구성안이 이전에 수동으로 그린 구성안과 정확히 일치하는지 확인; 타이틀 보이기/숨기기, 콘텐츠 패널, 미송출 워터마크, 2D 샘플 또는 3D/미정 자리표시자, 640×360 Canvas 설정 크기, 073 가상 음성 표시 태그와 처리 구간 일치를 검사합니다.
- 음량 0은 **'음소거 설정' 주의**로 보고하고 유효 범위의 그 외 음량은 실제 출력이 검증됐다고 표시하지 않습니다. 목소리 방식이 미연결이면 자동 대체하지 않습니다.
- 운영자는 `방송 화면 구성 미리보기` 탭에서 **현재 선택으로 미리보기 갱신 → 음량·방송 화면 점검 (오프라인)** 순서로 수동 실행합니다. 최초/선택 변경/음량 변경/대사 변경/가상 음성 단계 진행/화면 갱신 시 지난 결과는 즉시 무효 처리됩니다.
- Canvas 구조가 누락·오염되었을 때 점검 결과는 'Canvas 구성 불일치'이며, 화면을 직접 복구하거나 음량을 변경하지 않습니다.
- 여전히 **실제 방송/OS TTS/마이크/오디오 장치·권리 확인/실기기/Windows EXE**에 접근하지 않습니다. 사용자 최종 승인도 대기 상태입니다.

## 검증 근거

- `tests/test_offline_broadcast_output_audit.py`: 정상 2D, 3D/미정 자동대체 없음, 0·100·범위 외 음량, 제목 선택, 손상/무효/크기 불일치, 가상 음성 표시 경로, 읽기 전용·외부 접근 차단.
- `scripts/gui_offline_broadcast_output_audit_smoke.py`: 실제 Linux Xvfb Tk 인터페이스에서 초기 점검 차단, 화면 점검, 음량 0·85·잘못된 값, 가상 표시, 워터마크 훼손 감지, 3D 전환·기존 로컬 설정 불변 검사.
- 실제 실행 명령/원시 결과: `logs/STAGE75_UNITTEST.log`, `logs/STAGE75_SYNTAX.log`, `logs/STAGE75_GUI_NEW.log`, `logs/STAGE75_GUI_ALL.log`, `logs/STAGE75_FINAL_VALIDATION.txt`.

**주의:** 자동화된 GUI 구성 점검 통과는 방송 가능한 상태나 자연스러운 음성·화면 품질을 뜻하지 않습니다. 실제 소리 크기와 시청자에게 보이는 화면은 사용자 Windows 실기기·OBS 준비·권리·수동 승인 후 별도 검증해야 합니다.
