# 14단계 준비 — 필요한 프로그램·비용 일괄 사전 안내

`프로그램·비용 안내` 탭을 열면 **현재 로컬 실행**, **선택형 로컬 AI·EXE 빌드**, **향후 실방송**, **향후 확장 후보**, **기타 운영비**를 한 번에 볼 수 있습니다. `src/ai_broadcaster/software_cost_guide.py`의 고정 목록을 화면에 표시하는 기능으로, 인터넷·가격 비교·PC 설치 프로그램 조회·사용자 설정 파일 읽기·저장·설치·결제를 수행하지 않습니다.

## 현재 소스에 해당하는 항목

| 도구 | 사용 상태 | 비용 관련 주의 |
| --- | --- | --- |
| Windows PC 및 OS | 운영자 PC 실행 대상, 실기기 미검증 | 이미 보유한 OS와 새로 구입해야 하는 OS의 비용을 혼동하지 않음 |
| Python 3.11+ | 소스 실행 필요 | 무료 배포 선택지 있으나 PC 설치 여부 미확인 |
| Tkinter·sqlite3·JSON | 현재 소스가 사용하는 Python 표준 라이브러리 | 추가 유료 클라우드 API 불필요, 설치된 Python 빌드 구성 확인 필요 |
| 내장 2D 샘플 | 소스에 포함 | 실제 방송용 Live2D/VRM 모델은 아님 |
| Windows System.Speech | 설치된 음성만 선택형 사용 | 한국어 음성의 설치 여부 및 이용 조건 별도 확인 |

## 선택형 로컬 실행 / EXE 빌드

| 도구 | 상태 | 비용 관련 주의 |
| --- | --- | --- |
| Ollama | 사용자가 직접 켠 localhost 연결 코드만 존재 | 자동 설치/모델 다운로드 없음. 모델별 라이선스 확인 |
| 로컬 LLM 모델 | ZIP에 미포함 | 모델별 라이선스, PC 자원, 전기료, 저장 공간 확인 |
| PyInstaller | Windows 빌드 배치만 존재 | 무료 도구 선택지 있으나 실제 Windows 빌드/실행 미검증 |

## 향후 기능 후보 (현재 작동한다고 주장하지 않음)

OBS Studio·obs-websocket(송출/제어), 실제 Live2D 모델·VTube Studio(2D 방송 캐릭터), VRM 모델·렌더러(3D), 가상 오디오 케이블, Open-LLM-VTuber(원본 기획안의 권장 코어), GPT-SoVITS/RVC(동의·권리가 필요한 음성), Letta/ChromaDB(확장 기억), 공지 연동 도구 등은 **현재 통합 기능이 아닙니다**. 사용 여부도 미확정입니다. 상업 방송용 라이선스, 모델 제작·구매·의뢰비, 하드웨어와 서비스 이용 조건은 실제 도입 전에 확인해야 합니다.

## 비용·승인 기준

기본 모의 채팅과 2D 샘플은 **이미 보유한 Windows PC에서 Python을 실행할 수 있다는 조건** 아래 추가 클라우드 AI API 사용료 없이 실행하도록 작성되어 있습니다. 그러나 **Windows/PC 구입, GPU, 모델 저장 공간, 전기료, 인터넷, 방송용 캐릭터·음성 사용권**은 무료라고 단정할 수 없습니다. 전체 예상 총액은 **미산정**입니다. 실시간 판매가·라이선스 최신 약관을 조회하지 않았으므로 가격을 임의로 숫자로 채우지 않습니다.

이 안내는 **14단계 사전 안내 화면 구현**이며, 사용자 PC에 무엇이 설치되어 있는지 검사한 결과도, 14단계 사용자 확인 완료도 아닙니다. 10단계 최종 기준 승인, 11~13단계 실제 PC 확인, **15단계 설치 승인**은 모두 보류합니다. 승인 대기가 다른 개발을 멈추게 하지는 않습니다.

검증: `tests/test_software_cost_guide.py`, `scripts/gui_software_cost_guide_smoke.py`. Windows EXE 실기기 실행은 아직 검증하지 않았습니다.
