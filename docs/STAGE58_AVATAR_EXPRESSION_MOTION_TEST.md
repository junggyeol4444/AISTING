# v58 · 원본 개발 계획 057 — 표정 및 움직임 테스트

## 기존 기능과 신규 구현의 경계

기존 054 표정 수동 선택, 055 가상 음성→2D 입 프레임, 056 가상 타임라인은 그대로 유지합니다. 이번에는 **내장 2D 샘플 렌더러의 표정·입 움직임·눈 깜빡임이 모의 프레임마다 올바르게 표시되는지** 실제 Tk Canvas의 요소를 구조 검사하는 `avatar_motion_review.py`를 추가했습니다. 기획안의 운영자 판단 원칙을 유지합니다.

- 9개 수동 프레임: 대기·눈 깜빡임 → 발화·입 열림/변화 → 발화 종료·입 닫힘 → 대기·눈 열림 → 반복 눈 깜빡임 → 대기 복귀.
- 각 프레임에서 기존 선택 표정 4종 중 현재 값, 입 열림/닫힘, 눈 열림/깜빡임, 캐릭터 표시 이름과 배경 일치 여부 검사.
- 눈 객체에 `aisting_eyes_blink`와 `aisting_eyes_open` 태그를 부착해 실제 Canvas 결과를 확인합니다. 기존 2D 샘플 그림·색·좌표·입 애니메이션은 변경하지 않습니다.
- `표정·움직임 시험` 탭에서 **시험 준비 / 이전 / 다음 / 9단계 구조 검사** 버튼을 직접 클릭해야 검사합니다. 검사 후 사용자가 보고 있던 프레임을 복원합니다.
- 변경된 캐릭터·아바타·표정·시험 배경 설정은 이전 검사 결과를 무효화합니다. 3D/미정일 때 2D 대체 표시를 막습니다.
- 저장·설정 변경·SQLite·모델 및 미디어 파일 조회·오디오 재생·TTS·OBS·통신·프로세스 시작 없음. 별도 렌더러 설치도 실행하지 않습니다.

## 검증 범위

Canvas의 태그와 표시 문자열을 검사하는 **구조 자동 검증**입니다. 실제 이미지 품질, 표정의 심미성, 운영자가 느끼는 자연스러움, 음성 파형과의 정확한 입 모양 동기화, 실제 Live2D·VRM/Windows 장치·EXE 및 방송 연동의 성공을 의미하지 않습니다. 운영자 평가 및 승인은 별도 대기 상태입니다.
