# AISTING v03 — 별도 2D 아바타 창 (PC 완전 로컬)

이 구현은 Windows의 Tkinter GUI 안에 **아바타 탭**을 유지하면서, 사용자가
버튼을 클릭했을 때만 **별도 운영체제 창**을 만듭니다.
실제 방송 플랫폼, OBS API, 외부 네트워크는 호출하지 않습니다.

## 구현한 것
- **2D 아바타 → 아바타 별도 창 열기** 버튼.
- 본 프로그램 안과 별도 창의 캐릭터 이름/눈 깜빡임/입 모양이 동일한 프레임을 사용.
- 음성 재생 중 입이 움직이는 v02 기능 그대로 유지.
- 별도 창에서 **남색 스튜디오** 또는 **초록색 배경** 선택 가능.
  초록색 배경은 나중에 운영자가 OBS에서 크로마 키를 설정할 때 참고할 수 있는
  화면일 뿐, 프로그램은 OBS에 자동 소스를 추가하지 않음.
- 중복으로 열기 버튼을 눌러도 별도 창을 계속 새로 만들지 않음.
- 별도 창을 닫아도 AISTING 본 창, 채팅/음성은 유지.
- 본 창 종료 시 별도 창도 함께 종료.

## OBS 사용 시 (사용자 선택)
운영자 Windows PC에 OBS가 **이미 설치되어 있다면**, OBS의 창 캡처 메뉴에서
`AISTING 아바타 · 로컬 창 캡처용` 창을 **직접** 선택할 수 있습니다.
OBS 실행, 방송 송출, 외부 계정 연결, 장면 등록은 자동으로 수행하지 않습니다.
OBS가 없어도 별도 창 기능은 실행됩니다.

## 한계
- 현재 캐릭터는 Tkinter Canvas의 **무료 샘플**이며 정식 Live2D나 VRM 모델이 아닙니다.
- 입 동작은 음성 재생/데모 상태에 맞춘 반복 프레임입니다.
  **실제 음소/파형 분석을 이용한 정밀 립싱크가 아닙니다.**
- 이 Linux 테스트 환경에서는 Xvfb(가상 화면)에서 창 열기·그림·종료까지 검증했지만,
  실제 사용자 Windows PC의 OBS 창 캡처나 Windows EXE 생성은 검증하지 않았습니다.
- GitHub, 서버, 예약 실행 설정은 개발본에 포함하지 않습니다.
