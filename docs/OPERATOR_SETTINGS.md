## 화면 실행 (나중에 PC로 진행할 때)

이 작업은 설치/실행을 강요하지 않는다. 사용자가 PC를 켜고 설치와
실행을 승인하면 Python 3.11+에서:

\`\`\`bash
python scripts/settings_server.py
\`\`\`

브라우저: http://127.0.0.1:8765

- 설정은 **data/operator_settings.json**에만 저장되며 GitHub에 업로드되지 않도록 .gitignore로 보호된다.
- 서버는 **127.0.0.1**에만 바인딩된다. 외부 접근 불가.
- 설정 저장은 실제 송출, 계정 연동, 목소리 복제, 다운로드, 결제 등을 시작하지 않는다.
- 선택값은 향후 실제 LLM/TTS/아바타/OBS 구현 단계의 입력 자료로 사용한다.

## 확인과 한계

- PC가 켜졌다는 말이 오면 실제 PC 사양 및 OS를 확인하여 **한 번에** 설치 프로그램·무료 여부·계정 준비물을 알리고 승인받는다.
- 무료 소프트웨어만 써도 **이미 보유한 PC의 전기 사용, 인터넷 회선 비용, 장비 교체 비용 등은 0이라고 보장하지 않는다.**
- 로컬 언어 모델/TTS의 실제 속도와 자연스러움은 사양에 달려 있으며 아직 측정하지 않았다.
- YouTube/치지직/Twitch 실제 API 기능과 방송 정책은 연결 시점에 확인한다.
- **예약 자동화는 꺼진 상태**이며 사용자가 "예약"이라고 다시 지시하기 전에는 켜지 않는다.

## 상태

선택 화면 구현은 방송 플랫폼을 실제 선택했다는 뜻이 아니다.
100단계 진행률은 **2/100**, 3단계는 사용자가 화면에서
실제 방송 플랫폼을 선택할 때까지 미완료다.
