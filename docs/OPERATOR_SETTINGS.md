# 운영자 선택 조건 - Windows EXE

사용자가 선택한 기준:
1. 방송 플랫폼: 프로그램에서 선택 (복수 선택 가능).
2. 방송 콘텐츠: 프로그램에서 선택.
3. 캐릭터: 기본값 또는 직접 입력.
4. 목소리: 프로그램에서 선택 (사용 권리가 있는 음성만).
5. 아바타: 2D / 3D 등 선택.
6. 집 PC에서 실행.
7. 유료 프로그램, 구독, 유료 API, 유료 에셋은 사용하지 않음.

**설정 창은 브라우저 웹사이트가 아니라 AISTING.exe Windows 프로그램이다.**
로컬 PC의 Windows 사용자 폴더 LOCALAPPDATA/AISTING에 설정을 저장한다.
설정한다고 실제 방송이 켜지거나 계정을 연결하지 않는다.

PC를 켰다고 사용자가 말할 때만 PC 사양·필요 설치 사항·비용·계정 준비를
한 번에 설명하고, 승인받은 사항에 대해서만 설치/연결을 안내한다.
