# v60 / 원본 100단계 059 — 장시간 아바타 실행 테스트 (오프라인 가속 모의)

## 기획안/단계 연결

원본 `docs/ORIGINAL_PLAN.txt`의 24시간 자율 운영 목표와 100단계
`docs/ROADMAP_100.md`의 원본 059 `장시간 아바타 실행 테스트`를 기준으로 합니다.
이 단계에서 **실제 24시간 PC/모델 실행은 수행하지 않았습니다**.
운영자 승인 010 및 사용자 PC/Windows/실제 모델 평가와 구분해 코드 준비만 진행했습니다.

## 구현

- 기존 2D `AvatarFrame`, `draw_layout_preview`, 표정 선택을 재사용합니다.
- 수동 버튼으로 가상 1/6/24시간(초 단위 3,600/21,600/86,400프레임)을 빠르게 계산합니다.
- 20초마다 8초 발화/12초 대기의 **가상 상태**를 생성하고 입 개폐/눈 깜빡임/상태 수/순서를 검사합니다.
- 전체 프레임을 저장하지 않고 시작~끝 사이 **12개 체크포인트만** 보관합니다.
- 가상 상태의 SHA256 지문을 계산하여 동일 입력에서 결정적인 결과를 확인합니다.
- 실제 Tk Canvas에 대해 240회 화면을 반복 다시 그리며 프레임별 객체 수가 1~40개 범위인지 검사합니다. 완료/오류 시 최초 프레임으로 복원합니다.
- 사용자가 선택한 아바타/표정/캐릭터/시험 시간을 바꾸면 이전 결과를 무효화합니다.
- 3D/미정에서 내장 2D를 몰래 대신 실행하지 않습니다.
- 외부 서버, 음성, OBS, 파일 저장, PC 정보 조회, 자동 실행 타이머를 호출하지 않습니다.

## 결과 해석 주의

이는 **가속된 가상 타임라인 및 제한된 실제 Tk Canvas 반복 그리기 검사**입니다.
실제 1~24시간 연속 동작, 장기 메모리 누수, CPU 사용량 추이, OS/드라이버 안정성,
실제 음성/모델/OBS 송출, 시각적 자연스러움의 증거가 아닙니다.
원본 059 로드맵 체크박스 `[ ]`와 `config/roadmap.json`의 `pending`을 유지합니다.
코드 개발 도달 범위만 **59/100**으로 기록합니다.
