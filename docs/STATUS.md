# 개발 상태 — AISTING

- 완료: **1/100 목표·기획 기준 정리**, **2/100 핵심 기능 정의**.
- **3/100 방송 플랫폼 결정: 운영자 설정 화면 선택 대기**. 자동 완료하지 않음.
- 운영자 답변 확정: **플랫폼·콘텐츠·목소리·아바타는 선택형, 캐릭터는 기본값 또는 직접 선택, 내 PC 운영, 유료 프로그램/API/구독·에셋 구매 금지**.
- 새로운 개발 산출물: 로컬 PC 웹 설정 화면, 입력 검증, PC에만 설정 저장하는 안전한 백엔드와 테스트.
- 기존 코드 개발: 플랫폼 독립형 모의 방송 시작/종료 상태 머신, FIFO 채팅 큐, 외부 송출 승인 차단 및 테스트, 채팅→모의 응답→출력 파이프라인 및 출력 재시도. 실제 LLM/TTS는 미연결.
- 예약 상태: **중지**. ChatGPT 예약은 꺼졌고 GitHub Action의 schedule도 제거함.
- GitHub Actions는 push/PR/수동 실행 때 테스트만 수행하며 예약 실행은 없음.
- 실제 AI 라이브 방송, TTS, 아바타, OBS 연동: 미구현.
- PC 설치, 결제, 운영자 계정 연동, 실제 방송 플랫폼 선택: 미진행.

검증: \`python -m unittest discover -s tests -v\`
설정 화면 설명: \`docs/OPERATOR_SETTINGS.md\`

- 추가 기반 개발: 로컬 Ollama 호환 한국어 AI 응답 어댑터, PC 내부 주소 제한, 오류 시 채팅 보존 및 가짜 서버 테스트. **실제 모델 설치/실행 및 연동 테스트는 미진행**.
