# 18단계 · 기획안과 설정 파일 수동 보관 (v18)

이 기능은 **프로그램 안에서 사용자가 명시적으로 선택하고 확인할 때에만** 로컬 ZIP을 새로 생성합니다. 사용자 PC의 파일을 자동 수집하거나 외부에 전송하지 않습니다. 정기 백업·복원·설치·기획안 승인·실제 방송 기능이 아닙니다.

## 사용 방법

1. 앱의 상단 `화면 이동`에서 `기획안·설정 보관`을 선택합니다.
2. 기본 포함 자료는 `docs/ORIGINAL_PLAN.txt`, `config/requirements.json`, `config/roadmap.json`입니다.
3. 필요한 경우 `내 방송 설정` 또는 `수동 실행 환경 기록`을 **직접 체크**합니다. 기본은 모두 해제입니다. 파일이 없거나 검증 실패하면 ZIP을 생성하지 않습니다.
4. `보관 항목 미리보기`는 목록만 보여 주고 파일을 읽거나 만들지 않습니다.
5. `보관 ZIP 만들기 (수동)`를 눌러 **기존에 있는 로컬 폴더의 새 .zip 파일 이름**을 지정하고 확인 대화상자에 동의합니다.
6. 성공 시 ZIP 내부 `manifest.json`에 저장된 파일별 크기 및 SHA256과 실제 파일을 대조해 검증합니다.

## 포함/제외

| 분류 | ZIP 안의 경로 | 기본 포함 |
| --- | --- | --- |
| 원본 기획안 | `project/docs/ORIGINAL_PLAN.txt` | 예 |
| 요구사항 | `project/config/requirements.json` | 예 |
| 100단계 로드맵 | `project/config/roadmap.json` | 예 |
| 방송 선택 설정 | `operator/settings.json` | 아니요, 직접 체크 |
| 수동 실행 환경 | `operator/runtime_operator_profile.json` | 아니요, 직접 체크 |

원본의 절대경로는 ZIP에 저장하지 않습니다. SQLite 기억, 채팅 로그, PC 사양 기록, 운영체제 정보, 비밀번호, 계정 토큰은 **자동 포함하지 않습니다**. 선택한 설정에 개인 정보가 들어 있을 수 있으니 ZIP을 타인과 공유할 때 주의해야 합니다.

## 안전장치와 제한

- 승인 없이 파일을 저장하지 않습니다. 기존 ZIP 덮어쓰기, 원본 파일 수정/삭제, 폴더 자동 생성은 하지 않습니다.
- 원본 파일의 크기 제한(각 1MiB), 전체 제한, JSON 검증, 링크·정션 경로 거부, 기존 파일 충돌 방지, ZIP 무결성 검사를 적용합니다.
- 이 ZIP은 **보관 사본**입니다. 설정을 다시 앱으로 가져오거나 자동 복구하는 기능은 19단계에서 별도로 검토할 예정입니다.
- 앱 시작 시 자동 ZIP 생성, 예약 백업, 인터넷, GitHub, 프로그램 설치, PC 하드웨어 조회, OBS 송출은 없습니다.
- **10단계 최종 승인과 11~18단계 실제 사용자 PC 확인은 여전히 미완료**입니다. 개발 구현·Linux 가상 GUI 테스트가 사용자 승인이나 Windows 실기기 검증을 대신하지 않습니다.
