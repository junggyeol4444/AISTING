# 17단계 준비 — 기본 실행 환경 설정 (PC 로컬·수동)

**이번 구현 범위:** 앱 상단 **화면 이동** 메뉴에서 **기본 실행 환경**을 선택해 해당 탭으로 이동한 뒤, 채팅 연습에 사용할 응답 방식을 선택하고, 미리보기·수동 저장·수동 불러오기·수동 적용·기록 삭제를 할 수 있습니다. 기존 `settings.json`, `conversation.sqlite3` 및 16단계 작업 공간은 그대로 유지합니다.

## 선택 가능한 응답 방식

- **모의 답변 (인터넷 불필요):** 기본값. 모델 이름은 비워 둡니다.
- **로컬 Ollama (수동 선택):** 사용자가 이미 자신의 PC에서 준비한 Ollama의 모델 이름만 입력합니다. 모델 자동 검색·설치·다운로드·실행을 하지 않습니다. 네트워크 범위는 기존 코드와 같이 **`127.0.0.1:11434`**로 제한하며, **'모두 답변'을 눌렀을 때만** 로컬 모델을 호출합니다.

선택한 값은 `runtime_operator_profile.json`이라는 **별도 로컬 파일**에 저장할 수 있습니다. 저장 전 확인 창이 나오며, 취소 시 아무것도 기록하지 않습니다. 앱 시작 시 이 파일을 자동으로 읽거나 채팅 모드를 자동 변경하지 않습니다. 이전에 저장한 선택값을 적용하려면 **저장 기록 불러오기 → 채팅 연습에 적용**을 직접 누르세요. **저장과 적용은 서로 다른 작업**입니다.

모델 이름은 기존 로컬 Ollama 입력 규칙의 안전한 부분집합만 허용합니다. 외부 URL·공백·상대 경로 요소는 허용하지 않습니다. 실행 중인 채팅 연습은 임의로 전환하지 않습니다. 이전 연습이 구성된 상태라면 사용자가 **새 연습**을 눌러 초기화한 뒤 적용해야 합니다.

## 데이터 보존·승인 경계

- 저장·불러오기·삭제는 운영자가 버튼을 눌렀을 때만 수행합니다. 미리보기와 화면 열기만으로 파일/장치 조회, 파일 생성, 네트워크 연결, 프로세스 시작을 하지 않습니다.
- 저장 파일은 수동 실행(`manual_start_only=true`), 로컬 호스트(`127.0.0.1`), 방송/외부 게시 비활성화 조건을 기록하며 불일치 파일은 읽지 않습니다.
- 손상된 파일이나 알 수 없는 동명 파일은 덮어쓰거나 자동 삭제하지 않습니다. 심볼릭 링크/정션도 거부합니다. 정상 프로필 변경은 임시 파일을 통한 교체로 수행합니다.
- 사용자 확인 없는 설치, 프로그램 실행, 사용자 PC 사양 수집, 원격 서버, GitHub, 유료 서비스, 실제 계정 연결, OBS 방송은 없습니다.
- 10단계 개발 기준 최종 승인, 11~16단계 PC 실확인/승인, **17단계 실제 Windows 실행 환경 검증**은 모두 별개로 미완료입니다. 공식 로드맵 진행률은 **9/100** 그대로입니다.

## 테스트와 한계

`tests/test_runtime_profile.py`에서 모델 입력 검증, 로컬 정책, 저장·불러오기·삭제, 파일 보존, 오류 및 링크 방지, 무전송을 검사합니다. `scripts/gui_runtime_profile_smoke.py`는 GUI의 미리보기/취소/저장/불러오기/적용/삭제/연습 중 변경 차단을 검사합니다.

테스트는 Linux + Xvfb 가상 Tk 화면에서 수행하며 **Windows 10/11 실제 PC, EXE 빌드·실행, 실제 Ollama 연결 및 실제 방송은 검증하지 않습니다.**
