# v56 · 원본 055단계: 음성에 따른 입 움직임 연결 (오프라인 모의)

## 구현 범위

- 이전 v50의 `DialogueVoiceLink`를 재사용해 모의 채팅 → 모의 대사 → 가상 한국어 음성 구간을 차례로 전달합니다.
- 가상 음성 구간 **전달 성공 후에만** 2D 내장 아바타의 입 열림/열림/닫힘 프레임을 3개 기록합니다.
- 전달 실패/중단 시 해당 구간에 대한 움직임을 기록하지 않습니다. 실패한 채팅 및 나머지 채팅은 FIFO 대기열에 남으며 다음 운영자 클릭 때에만 재시도합니다.
- 새 `음성·입 움직임 모의` 탭에서 채팅 1건을 수동 전달하고, 생성된 프레임을 **한 장씩** 미리볼 수 있습니다. 자동 음성 재생·자동 대사 처리·파일 저장은 하지 않습니다.
- 기존 운영자 선택 표정(`기본·미소·놀람·걱정`)을 프레임에 유지합니다. 2D 미선택, 3D 선택 시 모의 연결을 차단합니다.
- 음성·아바타·표정 또는 시험 대본이 변경되면 구 모의 세션은 무효화됩니다.
- 실제 음성 재생에 종속하지 않는 별도의 **무음 시각화** 시험이며, 입 모양은 음소/파형 분석이 아닌 가상 전달 이벤트입니다.

## 보존 및 금지한 행동

기존 Windows 수동 음성 경로와 모든 플랫폼/콘텐츠/캐릭터/목소리/아바타 선택 기능을 유지했습니다. 기획안과 기존 설정·기억/SQLite·운영자 승인 기록을 수정하지 않습니다. 테스트 자체는 설치/스피커/마이크/OS 음성 목록 조회/사용자 PC 조사/실제 모델/OBS/계정/네트워크/GitHub/방송을 사용하지 않습니다.

## 검증되지 않은 것

실제 Windows TTS 재생과 발화 타이밍의 일치, 실시간 음성 파형 기반 립싱크, 외부 Live2D/VRM 모델 연결, 시각적 자연스러움, Windows 실기기/EXE 실행, 운영자 최종 승인은 **미완료**입니다. 원본 010단계 사용자 최종 승인 및 011단계 이후 PC 정보 확인도 계속 **별도 대기**입니다. 개발 진행 범위 **55/100**은 사용자 승인 완료 비율이 아닙니다.
