# 21단계 — 방송 코어 기반 프로젝트 준비 (로컬·비실행 구성도)

## 실제 구현

기존 v20 누적 소스 위에 `core_ports.py`, `core_foundation.py`를 추가했습니다.
`core_ports.py`는 입력·답변·기억·음성·아바타·송출의 **타입 계약(Protocol)** 및
입력/답변 자료형을 정의합니다. `core_foundation.py`는 현재 사용자 선택값을
**메모리에서만 검증**해 7개 구성 요소의 의존성과 구현 상태를 담은 불변 구성도를 만듭니다.
기존 `ChatRehearsal`, `MockReplyGenerator`, `LocalOllamaGenerator`, `LocalMemory`,
Windows 수동 TTS, 2D 샘플을 **교체하거나 실행하지 않고** 연결 대상/제약만 표시합니다.

데스크톱에 `방송 코어 구성도` 탭을 추가했습니다. 사용자가 버튼을 누르면
현재 `방송 설정` 화면의 플랫폼/콘텐츠/캐릭터/음성/아바타 선택과
`시청자 채팅 연습`에 적용된 응답 방식을 기준으로 구성도를 미리 봅니다.
저장되지 않은 선택값도 **저장하지 않은 채** 반영합니다. 플랫폼 미선택,
3D 선택, 미정 음성 등도 허용합니다. 유효하지 않은 선택값은 오류로 표시합니다.

구성도 상태는 **소스 존재 / 수동 미리보기만 / 미구현**으로 구분합니다.
모의 답변은 소스가 있고, 로컬 Ollama는 수동 선택 시에만 호출 가능한 기존
연습 소스가 있지만 연결 검증은 하지 않았습니다. SQLite 기억은 기존 연습용이고,
Windows 음성과 2D 샘플은 방송 송출에 연결되어 있지 않습니다.
**실제 방송 송출 및 통합 방송 코어 실행은 미구현**으로 강제 표시합니다.

`validate_blueprint()`는 필수 7개 구성 요소의 누락/중복, 순환·누락 의존성,
지원하지 않는 상태, 자동 실행/외부 송출 활성화, 실방송·통합 코어를
구현된 것으로 잘못 표시하는 것을 거부합니다. 별도 네트워크·PC 조회·설치·저장은 없습니다.

## 원본 기획안과의 관계

원본 기획안의 6-2에는 Open-LLM-VTuber를 **추천 기반 후보**로 제시합니다.
그러나 현재 대화의 명시 지시상 GitHub 접속/조회/다운로드·프로그램 설치가
금지되어 있으므로 외부 프로젝트를 가져오거나 통합하지 않았습니다.
기존 AISTING 오프라인 소스 내부에 향후 연결 가능한 타입 계약과 구성도만
준비했습니다. **Open-LLM-VTuber 기반을 확보·실행했다고 주장하지 않습니다.**

## 안전 경계 및 남은 작업

- 탭 열기/구성도 버튼은 PC 설정·SQLite 기억·원본 기획안·로드맵을 변경하지 않습니다.
- 실제 채팅 플랫폼 연결, 모델 설치, Ollama 요청, Windows TTS 재생,
  OBS 실행/방송 시작, 외부 업로드/계정 연결, PC 하드웨어 조회는 하지 않습니다.
- 22단계 **기본 코어 실행**은 별도 작업입니다. 23~30단계 모델 연결/한국어 응답
  검증과 61~90단계 방송 연동·자동화도 별도 미구현 영역입니다.
- 10단계 전체 개발 기준 최종 승인 및 11단계 이후 사용자 PC 실확인은
  승인/실기기 검증 전까지 `pending`; **공식 진행률 9/100 유지**.
- Windows 10/11 실기기, EXE 빌드, 실제 로컬 AI, 실제 방송은 미검증입니다.

## 검증 방법

- `python -m unittest discover -s tests -q`
- GUI 가능 환경에서 `python scripts/gui_core_foundation_smoke.py`
- 전체 기존 GUI 스모크 재실행 기록: `docs/VALIDATION_v21_gui.log`
- 단위 테스트 기록: `docs/VALIDATION_v21_unittest.log`
- 원본/파일 보존 및 구문/ZIP 검사: `docs/VALIDATION_v21_integrity.log`

## v22 이후 구현 구분

22단계에 별도의 **메모리 전용 모의 코어 실행**이 추가되었습니다(`core_execution.py`).
21단계 구성도에 표시된 통합 **실방송** 코어는 여전히 미구현이며, 외부 오픈소스 기반 실행/OBS 연동을 구현했다는 뜻이 아닙니다.
