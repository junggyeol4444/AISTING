## 구현 경계

기존 2D `draw_avatar`와 054단계 표정 설정을 재사용합니다. 640×360 가상 방송 화면 안에서 운영자가 **가로/세로 0~100%**와 **크기 40~100%**, 기존 배경을 선택할 수 있는 `캐릭터 화면 배치` 탭을 추가했습니다.

- Tk Canvas의 `scale`/`move`로 실제 샘플 도형을 재배치하며, 소스 도형 전체가 가상 화면 영역 안에 있도록 비율을 제한합니다.
- 배치 설정을 바꾸면 미리보기는 다시 그리지만 **디스크에는 자동 저장하지 않습니다**. 확인 후 별도 JSON `avatar_layout_draft.json`에만 기록하며 수동 불러오기, 2회 확인 삭제가 가능합니다.
- JSON 스키마·좌표 유형/범위·자동 승인 플래그를 엄격히 검사합니다. 손상 기록/심볼릭 링크 및 3D·미정에서의 2D 배치 재사용을 거부합니다.
- 3D 선택 시 실제 모델이나 2D 대체 렌더링을 수행하지 않고 미지원 메시지만 보여 줍니다.
- 기존 플랫폼·콘텐츠·캐릭터·목소리·아바타 선택, 2D 별도 창, SQLite 기억, 기존 사용자 설정 및 기획안은 유지합니다.
- 실제 OBS 화면·카메라·TTS·외부 Live2D/VRM의 레이아웃이나 방송 송출에는 **적용되지 않습니다**.
