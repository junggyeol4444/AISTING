# v93 / 원본 092 과거 방송을 기억하는 기능 구현 — 오프라인 부분

## 실제 구현한 범위

- 기존 091 **가상 방송 대화·사건 기록 JSON** 파일을 운영자가 직접 한 개씩 선택해 불러온다. 기존 `OfflineBroadcastJournal.load_json`의 구조·SHA256 무결성 검증을 통과한 파일만 기억 카드 후보로 사용한다.
- 한 회차에서 최대 12개 문구를 추출한 **가상 기억 카드**를 최대 20개까지 보관한다. 같은 원본 체크섬으로 재가져오기 방지. 사건/운영자 메모만 기본 포함하고, **가상 채팅 문구는 운영자가 체크박스를 직접 켜야만** 포함한다. 실제 신원·채팅 데이터는 자동 수집하지 않는다.
- 화면에 기억 카드/포함 문구를 표시하고, 운영자 확인 후 선택 삭제한다. 수동 JSON 내보내기는 기존 파일을 덮어쓰지 않는다(`open('xb')`). 수동 불러오기는 구조·중복·길이·승인/실방송 불변 플래그 및 SHA-256 무결성을 검증하고, 실패하면 기존 메모리 기록을 그대로 보존한다.
- `mock_only=true`, `auto_collected=false`, `real_platform_collected=false`, `ai_connected=false`, `actual_broadcast_verified=false`, `approval=pending` 고정. 사용자 계정/OS/OBS/네트워크/AI/음성 장치에 접근하지 않는다. 기존 방송 선택 설정/SQLite 기억/원본 문서는 건드리지 않는다.

## 의도적으로 개발하지 않은 부분과 한계

- 이 단계는 사람이 검토할 수 있는 **오프라인 과거 회차 메모 저장/재확인**만 제공한다. 실제 AI 모델의 장기 기억, 의미 이해, 벡터DB, 현재 대화에 기억을 삽입하는 기능은 **미구현**이다. 원본 **093 기억 검색과 다음 방송 연동**은 다음 단계로 남겨둔다.
- 091 가상 기록 중 최대 12건만 선택하고, 실방송 자료를 가져올 수 없다. JSON은 평문이며 체크섬은 비밀키/서명/암호화가 아니다. 실명·실제 채팅·민감정보·계정 토큰을 이 시험에 넣으면 안 된다. 개인정보 적법성·보유기간·삭제·권한 정책은 사용자 승인 후 검토가 필요하다.
- 로컬 JSON 파일을 사용자가 직접 선택했을 때만 읽거나 쓴다. 폴더 자동 탐색·자동 불러오기·자동 방송 시작 없음. 실행 종료 후 자동 저장/복원 없음. 저장 중 중단/디스크 오류에서 부분 파일이 생길 수 있어 Windows 실기기 확인 필요.
- 실제 로컬 TTS/3D/OBS/채팅 연동, Windows/EXE 및 자연스러움, 모델의 정확한 회상/환각 방지, 1~3시간 장시간 실행은 검증하지 않았다. 개발 단계 도달 92/100은 실제 제품 완성도가 아니다.
- 원본 092 완료 승인과 010 최종 사용자 승인 상태는 `pending` 유지. `config/roadmap.json` 불변.
