# 26단계 — 대화 맥락 전달 구조 시험 (로컬 모의 전용)

## 실제 구현

`core_execution.py`의 `OfflineCoreSession.context_for_next_turn`은 다음 답변 포트에 전달할 **최근 최대 8개 처리 완료 입력·답변**을 튜플 스냅샷으로 제공합니다. `process_one()`은 그 스냅샷을 사용합니다. 메모리 이력 자체는 최대 500건이고, 기존 입력 FIFO·중복 보존·실패 시 미처리 보존 정책을 유지합니다. 별도 파일/네트워크/모델 조회가 없습니다.

`context_retention_test.py`는 **매번 새로운 메모리 세션**과 `ContextWitnessPort`를 만들어 사용자 대본(2~30건, 10,000자 이하)을 처리합니다. 응답 포트가 실제로 받은 직전 이력의 순서, 닉네임, 원문, 응답 내용, 중복, 최대 8건의 상한을 **이전에 처리된 실제 결과와 비교**합니다. 모의 포트는 직전 입력을 문자 그대로 답변에 포함하고, 답변 일련번호를 붙여 동일한 채팅도 구분합니다. 기본 예시는 11건으로 10번째 이후 오래된 이력 제거 경계를 포함합니다. 9건 이하의 짧은 사용자 대본은 잘림 경계가 검사되지 않았음을 명시합니다.

GUI `대화 맥락 전달 시험` 탭은 수동 실행/대본 편집/예시 재설정/건별 검증 결과를 제공합니다. 로컬 Ollama 선택 여부와 무관하게 **실제 모델 연결은 수행하지 않습니다**. 사용자 설정, SQLite 기억, 기존 기본 코어 세션 및 채팅 연습 세션을 읽거나 변경하지 않습니다.

## 한계와 보류

**맥락 전달의 구조적 정확성**만 검증합니다. 실제 AI의 의미 이해, 지시대명사 해석, 주제 지속성, 장기 기억, 한국어 자연스러움은 검증하지 않았습니다. 최근 8건 이전의 맥락은 포트에 전달하지 않으며 영구 저장되지 않습니다. 실제 Windows PC, EXE, 로컬 AI 모델 품질 시험은 사용자 승인 후 별도 수행해야 합니다. 10단계 최종 승인 및 11단계 이후 PC 확인은 `pending`, 공식 진행률 9/100 유지.

## 재현

- 자동: `python -m unittest discover -s tests -q`
- GUI (Linux 가상 화면): `xvfb-run -a python scripts/gui_context_retention_smoke.py`
- Windows GUI: 이미 설치된 Python/Tkinter에서 `scripts/run_desktop.py` 실행 후 `화면 이동 → 대화 맥락 전달 시험` 선택. 사용자 PC에서의 실검증은 별도 승인 필요.

회귀 테스트에는 결함 주입(이력 전달 누락), 응답 중간 실패, 중복·다중 화자·9/10건 경계, 500건 이력 보관 한도, 재시작 시 격리, 설정 무변경·네트워크/SQLite/프로세스/PC 조회 차단을 포함합니다.
