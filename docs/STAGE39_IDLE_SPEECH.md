# 누적 소스 v39 · 원본 로드맵 038 무채팅 자발적 발화 구현 (오프라인 모의)

## 근거

원본 기획안 `docs/ORIGINAL_PLAN.txt` 3-2는 **채팅이 정말 없을 때만** 능동 발화를 허용하고, 너무 자주 이야기하는지/무엇이 자연스러운지는 운영자 판단으로 조정하도록 명시합니다. 4-2는 채팅이 있으면 먼저 반응하고, 없을 때에만 혼잣말을 고려합니다. 100단계 로드맵의 038은 **채팅이 없을 때 자발적 발화 구현**입니다. 원본 계획은 건드리지 않았습니다.

## 실제 구현(새 파일)

- `src/ai_broadcaster/idle_speech.py`는 기존 `AllChatPolicySession`을 재사용하고, 수동으로 입력하는 **가상 시간**과 운영자 승인 플래그를 분리하여 관리합니다. 사용자가 체크하고 `모의 규칙 적용`을 눌러야 활성화됩니다. 운영자 지정 무채팅 기준 1~3600초, 자유 편집 문구 최대 240자. 기본 활성화는 꺼짐입니다.
- 모의 발화는 **채팅 대기·실패·처리 보류가 하나라도 있으면 금지**됩니다. 중복 채팅은 고유 순번/정확한 순서로 처리하며, 채팅 응답에 인위적 지연을 도입하지 않습니다. 모의 채팅을 새로 접수하면 무채팅 시간과 발화 구간을 다시 시작합니다.
- 기준에 도달해도 후보는 사용자가 `발화 후보 확인` 버튼을 눌렀을 때 한 번만 표시됩니다. 무채팅 구간당 **최대 1개**, 반복 타이머·백그라운드 자동발화 없음. 문구는 운영자가 입력한 원문입니다. **LLM의 대사 자동 생성이 아닙니다.** 기존 음성/TTS, 아바타, 방송 기능에는 연결하지 않습니다.
- GUI `무채팅 자발 발화 모의` 탭에서 운영자 허용/해제, 발화 예시, 가상 시간, 채팅 접수/처리/실패 수동 재시도/확인 후 초기화를 진행할 수 있습니다. 설정 파일·SQLite 및 기존 다른 탭의 모의 데이터는 읽거나 덮어쓰지 않습니다.
- `tests/test_idle_speech.py`는 기본 비활성, 가상 기준 시간, 재발화 방지·채팅 우선순위, 중복/FIFO, 실패 처리와 수동 재시도, 원자적 검증, 네트워크/파일/PC 조회 무호출을 검사합니다. `scripts/gui_idle_speech_smoke.py`는 Linux Xvfb 화면에서 동작을 확인합니다.

## 아직 완료가 아닌 항목

- 실제 AI 모델이 맥락을 고려해 **새 발화 내용을 생성하는 기능** 및 실제 시간 기반 자율 운영, 음성 출력, 실제 시청자 채팅 수신/방송 연결은 구현/검증하지 않았습니다. 이번 단계는 그 정책을 순수 로컬 모의로 검사하는 구현입니다.
- 어떤 기준과 말투가 자연스러운지는 사용자가 결정합니다. **10단계 전체 최종 승인 미완료**, **11단계 이후 실제 사용자 PC 조회·Windows EXE/실기기 검증 미완료** 상태를 유지합니다.
- 사용자 승인 없는 GitHub·클라우드/외부 연결·프로그램 설치·결제·계정 접속·OBS/방송 시작·원격 PC 제어는 수행하지 않았습니다.
