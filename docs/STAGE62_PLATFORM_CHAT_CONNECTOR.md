# v62 · 원본 100단계 061 — 방송 플랫폼 채팅 연결 (오프라인 계약 모의)

## 원본 기준

`docs/ORIGINAL_PLAN.txt`의 플랫폼 채팅 → AI 반응 구조와 `docs/ROADMAP_100.md`의 **061 방송 플랫폼 채팅 연결**을 기준으로 한다. 사용자 요구에 따라 치지직·유튜브·트위치를 **프로그램에서 자유롭게 복수 선택·변경**하는 기존 003 기능을 재사용한다. 플랫폼 계정·권한·실시간 연결이 필요한 작업은 승인 대기로 둔다. 다음 062 실시간 채팅 수신을 미리 구현한 것으로 간주하지 않는다.

## 실제 구현

- `platform_chat_connector.py`: 세 플랫폼 식별자와 가상 연결 상태에 대한 **메모리 전용 계약**. 연결은 사용자가 직접 버튼을 누른 경우에만 시작한다. 초기에는 모두 미연결이다.
- 복수 선택 시 가상 핸드셰이크를 **원자적으로** 성공 처리한다. 가상 장애 주입 시 일부만 연결됐다고 보고하지 않고 모두 미연결로 복구하며 자동 재시도하지 않는다.
- 연결 중 다시 연결하려는 요청은 차단한다. 수동 해제·재연결은 별도 버튼을 눌러야 한다.
- `desktop.py`의 `플랫폼 채팅 연결 모의` 탭은 현재 방송 설정 체크박스를 읽고 선택 변경 시 기존 가상 연결을 무효화한다. 기존 설정 파일·사용자 자료는 변경하거나 저장하지 않는다.
- 소켓, HTTP, 웹소켓, 인증/토큰, 채팅 수신, OBS, 예약 작업, 외부 프로세스, DB, 디스크 입출력은 이 기능에서 사용하지 않는다.
- `tests/test_platform_chat_connector.py`의 20개 테스트와 `scripts/gui_platform_chat_connector_smoke.py`가 선택/무선택/복수/중복/장애/수동 재연결/무효화/외부 I/O 금지를 검사한다.

## 완료 판정 경계

**실제 플랫폼 채팅 연결은 0건**이다. 모의 연결 성공은 실서비스 연결, 사용자 권한, 플랫폼 정책 적합성, 채팅 실시간 수신, Windows 실기기 검증 또는 운영자 승인에 해당하지 않는다. 061의 로드맵 체크박스 및 JSON 상태는 `pending`을 유지한다. 코드 개발 도달 범위만 **61/100**이다. 010 사용자 최종 승인, 011+ 사용자 PC 검사, 실제 연결 및 운영자 검증은 대기 상태다.
