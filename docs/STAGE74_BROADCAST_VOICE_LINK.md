# v74 · 원본 073 음성 방송 출력 연결 — 오프라인 무음 시험

**공식 단계:** `073 음성 방송 출력 연결`. 본 개발은 해당 단계 중 운영자 승인·실기기·송출 없이 수행할 수 있는 **무음 가상 연결**만 구현한 것입니다. 공식 체크박스 `[ ]`와 `config/roadmap.json`의 `pending`은 변경하지 않습니다. 코드 구현 도달 범위 **73/100**이며 제품 완성 또는 실제 방송 가능을 의미하지 않습니다.

## 기존 기능과의 연결

- 원본 071 `offline_broadcast_scene.BroadcastSceneDraft`의 현재 플랫폼/콘텐츠/캐릭터/목소리/아바타/배치 구성을 사용하며 새로운 방송 설정 저장소를 만들지 않습니다.
- 원본 072 내장 2D Canvas 미리보기 및 3D 미연결 처리 정책을 그대로 유지합니다. 3D를 임의로 2D로 바꾸지 않습니다.
- 기존 `offline_tts.speech_chunks`로 텍스트를 분할하되 **음성 합성기는 호출하지 않습니다.** 실제 설치된 음성 목록이나 장치도 조회하지 않습니다.
- 현재 음성 출처가 `windows_system`으로 명시 선택된 경우에만 **무음 가상 경로** 시험이 가능합니다. 설치되었거나 방송 사용 권리가 있다는 보증이 아니며, `미정/본인 녹음/동의받은 녹음/라이선스 음성`은 다른 음성으로 대체하지 않고 막습니다.

## 운영자 사용법

1. `방송 설정`에서 `Windows 무료 음성`을 선택합니다(실제 재생할 필요 없음).
2. `방송 화면 구성 미리보기` 탭에서 테스트 대사 입력 후 `가상 음성 경로 준비`를 직접 누릅니다.
3. `다음 구간 표시`를 누를 때마다 무음 텍스트 구간을 기존 Canvas의 표시 태그에 표시합니다. 스피커 출력/믹싱/OBS 전송은 없습니다.
4. `중단 모의`는 해당 구간을 소비하지 않으므로 `다음 구간 표시`로 운영자가 수동 재개할 수 있습니다. 실패해도 자동 재시도하지 않습니다.
5. 대사나 플랫폼/콘텐츠/목소리/캐릭터/아바타/배치/화면 표시 설정이 변경되면 기존 연결을 무효화합니다.
