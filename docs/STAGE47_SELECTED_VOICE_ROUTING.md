# v47 / 원본 046 — 선택한 목소리 적용 (비재생 경로 검증)

## 기존 기능 재사용과 이번 구현

- 기존 `voice_choices.py`의 `preferred_installed_voice`와 `offline_tts.py`의 `KoreanVoice`·`speech_chunks`, `offline_settings.py`의 음성 프로필 검증을 재사용합니다. 사용자 목소리 복제, 새 음성 엔진, 클라우드 의존성은 추가하지 않습니다.
- `selected_voice_routing.py`는 **이미 제공된 목소리 목록** 중 운영자가 명시적으로 선택한 `ko-KR` 목소리의 **정확한 이름·속도·음량**을 가상 출력 단계마다 전달하는지 확인합니다. 목록에 없거나 프로필이 다른 이름이면 자동 대체 없이 거부합니다.
- 중복/긴 문장의 분할·순서 보존, 두 번째 구간에서 중단·예외가 발생할 경우 미처리 구간 보존, 자동 재시도 없음, 오류 상세 비노출을 시험합니다.
- 새 `선택 목소리 적용 모의` 화면에서 운영자가 모의 실행 버튼을 눌렀을 때에만 검사합니다. **이 화면을 열거나 모의 검사할 때 음성 조회·OS/PC 검사·오디오/프로세스·SQLite·외부 네트워크 사용 없음.** 운영자가 별도의 `무료 한국어 음성` 화면에서 기존 `음성 목록 확인` 버튼을 누르는 행위는 이 검사의 일부가 아닙니다.
- 기존 실제 Windows System.Speech 수동 재생 경로에서 **현재 확보 방식이 `Windows 무료 음성`이 아니면** 실행 버튼을 비활성화하고 직접 호출해도 재생을 거부하도록 보강했습니다. 자동 읽기 기본 꺼짐 유지.
- 모의 대본·목소리 선택·속도·음량·실험 모드가 바뀌면 이전 화면 검증 결과를 무효화합니다. 로컬 설정·SQLite 및 원본 기획안은 자동 수정하지 않습니다.
