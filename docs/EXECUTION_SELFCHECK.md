# 20단계 — 개발 환경 실행 자가점검 (사용자 수동 실행)

## 목적과 실제 구현 범위

AISTING 프로그램의 **개발용 오프라인 샘플 실행**이 현재 소스에서 가능한지 확인하는 기능입니다. GUI의 `개발 환경 자가점검` 화면에서 **오프라인 샘플 자가점검 실행 (수동)** 버튼을 눌러야 시작합니다. 프로그램 실행/탭 열기만으로 검사가 자동 시작되거나 사용자 PC 사양·프로그램 설치 상태·계정 정보를 읽지 않습니다.

수동 점검은 다음 5가지를 실행합니다.

1. 앱에 포함된 `requirements.json`, `roadmap.json`을 읽고 핵심 원칙, 100단계, 사용자 승인 대기 상태를 확인합니다. 사용자 개인 설정 파일은 읽지 않습니다.
2. 플랫폼·콘텐츠·아바타·목소리 선택 **240개 조합**을 메모리에서 검증하고 로컬 전용 정책을 확인합니다. 특정 옵션을 사전에 확정하지 않습니다.
3. 운영자 데이터 폴더가 아닌 임시 디렉터리에서 **샘플 설정** 저장/재읽기를 실행합니다.
4. 인터넷 없이 모의 채팅 3건을 FIFO로 응답하고 중복 메시지 보존을 검사합니다.
5. 임시 디렉터리에서 **샘플 SQLite** 2건을 저장/조회합니다.

검사 종료 시 임시 디렉터리를 정리합니다. 검사에 실패하면 실패 항목과 원인을 화면에 표시하며 성공으로 간주하지 않습니다. 임시 디렉터리 생성에 실패한 경우 실제 사용자 데이터 폴더로 대체하지 않습니다.

## 수동 CLI 실행 (선택)

이미 설치된 Python에서 소스 프로젝트 폴더 기준:

`python scripts/run_environment_selfcheck.py`

실패 시 종료 코드 1, 5개 항목 모두 통과 시 종료 코드 0입니다. 설치·다운로드·서버 연결·프로세스 실행을 하지 않습니다.

## 보존/승인/검증 경계

- 기존 방송 선택값, 원본 기획안, 사용자 `settings.json`, `conversation.sqlite3`, 10단계 승인 기록을 읽거나 수정하지 않습니다.
- 테스트 실행에 사용하는 임시 설정/기억은 **사용자 PC의 실제 설정/기억이 아닙니다**.
- 10단계 최종 승인 및 11~20단계 실제 PC 확인은 사용자 승인 전 `pending`으로 유지합니다. 공식 완료는 9/100입니다.
- **Windows 10/11 실기기 실행, EXE 빌드, 사용자의 OS/CPU/RAM/GPU, 실제 한국어 음성, 로컬 Ollama 연결, OBS, 실방송은 검증하지 않습니다.** 별도 승인·환경이 필요합니다.
- GitHub, 외부 서버, 유료 서비스, 자동 설치, 사용자 PC 원격 제어를 사용하지 않습니다.
