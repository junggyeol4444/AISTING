# 11단계 준비 — PC 운영체제 확인 (수동 입력, 실기기 검증 전)

- 사용자가 **PC를 켜고 직접 확인하기 전에는** PC 시스템 정보에 접근하지 않습니다.
- AISTING Windows GUI의 **OS 확인 준비** 탭에 사용자가 아는 운영체제 종류 및 시스템 비트를 직접 고를 수 있습니다.
- `선택 내용만 평가`는 사전에 정의된 호환성 안내 문자열을 만들 뿐, OS/CPU/RAM/GPU, 레지스트리, 프로세스나 네트워크를 **조회하지 않습니다**.
- `입력 내용 PC에 기록`은 사용자에게 확인 대화상자를 보여준 뒤 별도 JSON에 **직접 입력 정보만** 보관합니다. JSON에 실기기 검증 완료를 뜻하는 필드는 없습니다.
- 기록은 `os_operator_note.json`에만 저장됩니다. 기존 방송 설정, 캐릭터 설정, 대화 기억, 10단계 개발 기준 승인 기록을 변경하지 않습니다.
- `지난 입력 불러오기`, `입력 기록 삭제`는 각각 사용자 버튼으로만 작동합니다. 삭제 전에 별도 확인을 요구합니다.
- 실제 설치된 운영체제와 CPU/메모리/GPU는 **확인하지 않았습니다**. Windows 10/11 x64를 선택하더라도 현재 빌드 스크립트의 후보라는 의미이며 AISTING.exe 작동 보장이나 실기기 시험 통과가 아닙니다. ARM64·x86 등은 별도 확인이 필요합니다.
- 테스트는 사전에 만든 입력값과 모의 GUI에 대해서만 진행합니다. Windows EXE 실물 빌드·실행 검증은 미완료입니다.
- 사용자 승인 전의 **10단계 최종 승인과 11단계 운영체제 실측**은 완료 처리하지 않습니다. 공식 진행률 9/100 그대로 유지합니다.

### 실행 검증

`python -m unittest discover -s tests -v`

GUI 화면 가능 환경: `python scripts/gui_os_readiness_smoke.py`

GitHub 서버/API, 외부 방송 플랫폼, 유료 서비스, 자동 예약과 관계없는 순수 로컬 기능입니다.
