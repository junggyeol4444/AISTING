# 누적 개발본 v36 · 원본 100단계 중 미완료 035 '기본 대화 반응 테스트'

## 개발 순서 구분

v35에서 직전 작업 약속에 따라 운영자 지정 금기·제한사항 입력 화면을 구축하였으나, 원본 `config/roadmap.json`과 `docs/ROADMAP_100.md`의 035단계는 **'기본 대화 반응 테스트'**이다. 본 v36 개발은 이 누락된 검증을 구현했다. 파일 버전 v36은 원본 계획의 036단계 '자연스러운 응답 속도 확인' 완료를 의미하지 않는다.

## 실제 구현

- `src/ai_broadcaster/basic_reaction_test.py`: 사용자가 입력한 최대 30개 채팅을 별도의 **메모리 내 모의 코어**로 전부 처리. 각 입력의 순서·복제 여부·응답 수·성공 처리 여부·직전 8건 맥락 순서 확인.
- 기본 예시: 빠른 인사, 'ㅋㅋㅋ', 중복 채팅, 질문, 감사, 신규 시청자. 중복은 별도 입력으로 다룸.
- 실패 시 아직 처리하지 않은 입력의 개수를 보여주고 중단. 실패에 대한 **자동 재시도·자동 무시 없음**. 포트 예외 메시지에 개인 정보가 있을 수 있어 보고서에 원문 미노출.
- `src/ai_broadcaster/desktop.py`: '기본 대화 반응 검사' 탭, 편집 가능한 예시, 사용자 버튼 실행, 원문 복원, 구조 결과 표시.
- 오프라인 모의 응답만 검사하며 실제 AI의 의미 이해, 자연스러움, 주관적 평가, 실제 응답 지연, 방송 처리량, 금기 출력 준수는 검사하지 않는다. 응답을 일부러 지연하는 규칙은 새로 추가하지 않았다.
- 기획안에 따라 운영자가 입력하지 않은 캐릭터 금기·반응 방향을 자동 설정하거나 모델에 적용하지 않음.
- 설정·SQLite·기존 모든 콘텐츠/플랫폼/캐릭터/목소리/아바타 선택을 유지; 사용자 PC 조회, 네트워크, OBS, 외부 API, 파일 쓰기 없음.

## 검증

자동: `PYTHONPATH=src python -m unittest discover -s tests -q`

GUI: `PYTHONPATH=src xvfb-run -a python scripts/gui_basic_reaction_smoke.py` (Linux 가상 디스플레이, Windows 실기기 테스트와 구분)

**승인과 검증은 분리**: 10단계 사용자 최종 승인/11단계 이후 사용자 PC 실제 확인은 대기. 실제 Windows EXE/모델 접속/방송은 사용자 별도 확인 전 미실행. 다음 원본 계획의 승인 불필요 작업은 036 '자연스러운 응답 속도 확인'의 오프라인 계측 기반 준비.
