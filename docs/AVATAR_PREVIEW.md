# Windows EXE 2D 아바타 샘플과 음성 재생 중 입 움직임

사용자는 프로그램을 **EXE**로 제공하고, 2D/3D 아바타를 나중에 선택하길 원합니다.
외부 다운로드·유료 에셋·라이선스 문제 없이 먼저 테스트 가능한
**Tkinter Canvas의 자체 제작 기본 2D 캐릭터 샘플**을 넣었습니다.

## 현재 구현
- AISTING.exe의 별도 **2D 아바타** 탭에서 기본 캐릭터(머리·눈·입·상반신) 표시.
- 캐릭터 이름은 프로그램의 기본값/사용자 입력과 연동.
- 사용자 버튼 없이도 아주 가벼운 눈 깜빡임 표현.
- AI 답변 TTS 또는 한국어 음성 미리 듣기를 **사용자가 직접 시작했을 때**
  2D 샘플의 입 모양을 전환하고 음성 종료·실패 뒤에는 입을 닫음.
- 음성이 없어도 '음성 없이 입 움직임 테스트'로 애니메이션 확인 가능.
- 서로 다른 두 TTS 재생 작업이 중첩되면 마지막 음성이 종료될 때 정지.
- 재생 이벤트와 Tk GUI는 안전하게 분리해 스레드에서 Canvas를 만지지 않음.
- 코드/모의 테스트는 외부 Python 패키지·게임·오디오 라이브러리 불필요.

## 정직한 구현 경계
- **이것은 실제 Live2D/VRM 아바타가 아닙니다.**
- 입 모양은 오디오 구간별 음소·파형 분석이 아닌 **재생 중 여부 기반 반복 애니메이션**입니다.
- 모션의 자연스러움은 운영자의 판단이 필요하며, 아직 사용자 PC에서 확인하지 않았습니다.
- 기존 아바타 형태 선택은 미정/2D/3D 모두 유지하지만 이 화면은 **2D 데모 전용**입니다.
- OBS 송출, 립싱크 음성 분석, 외부 방송 자동 시작, 플랫폼 연결은 아직 미완성.
- 비용·외부 API·프로그램 설치 없음. 예약 작업 중지 유지.
