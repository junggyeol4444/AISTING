# 23단계 — 코어 AI 모델 연결 방식 설정 (오프라인 계획만)

## 구현

`src/ai_broadcaster/core_ai_connection.py`는 모의 답변과 동일 PC Ollama 후보의 연결 **계약**을 만들고 검사합니다. 실제 모델 실행/접속 코드는 없습니다. 17단계의 `RuntimeProfile` 입력 검증과 안전한 수동 파일 기록 방식을 재사용하되 코어 계획 파일은 `core_ai_operator_profile.json`으로 분리해 기존 채팅 연습 설정을 변경하지 않습니다.

- **모의 답변:** 모델 이름 없이 네트워크 없는 모의 포트만 사용.
- **동일 PC Ollama 후보:** 운영자가 직접 모델 이름을 입력. 향후 연결 경로는 `127.0.0.1:11434/api/generate`로 고정. 현재는 이 주소에 요청하지 않고 설치/실행 여부도 조회하지 않음.
- **금지:** 외부 호스트, 포트 변경, 임의 API 경로, URL 형태 모델 이름, 자동 시작, 자동 네트워크 연결, 실제 방송 송출, 클라우드 API.
- **코어 적용:** `OfflineCoreSession.configure_ai_plan()`은 검증된 계획만 정규화해 메모리에 보관. `MockCoreReplyPort`를 다른 포트로 바꾸지 않음. 기존 입력 대기열, 처리 이력, 선택형 설정, SQLite 기억, 채팅 연습 세션에 영향 없음.
- **수동 저장:** 사용자 확인 대화상자 이후에만 별도 로컬 JSON 파일 저장. 불러오기는 버튼 클릭 시에만 실행되며 코어에 자동 적용하지 않음. 삭제도 확인 필요. 손상된 기존 기록/링크·정션은 덮어쓰기/삭제 차단.

## 사용법

`코어 AI 연결 방식` 탭에서 모의 또는 로컬 Ollama 후보를 선택하고, 로컬 후보인 경우 모델 이름을 입력합니다. **연결 방식 미리보기**로 순수 메모리 계획을 확인하고, **코어에 계획만 적용**을 누르면 현재 코어 세션에 선택 계획을 기록합니다. 이후 `기본 코어 수동 실행`에서 실행하는 답변은 계속 **모의**입니다. 저장·불러오기·삭제는 각각 별도 버튼을 사용합니다.

v24에서 **24단계 AI 연결 시험**의 오프라인 가상 프로토콜 검증과 사용자 승인 후 단발 로컬 `/api/tags` 조회 코드를 추가했습니다. 실제 Windows PC에서의 연결 시험은 아직 수행하지 않았습니다 (`docs/CORE_AI_PROBE.md`). 기존 17단계의 선택적 로컬 Ollama 채팅 연습 기능은 그대로이며, 이 탭이 이를 자동 실행하거나 변경하지 않습니다.

## 검증 및 제한

`tests/test_core_ai_connection.py`는 모드/모델 입력, 원격 주소·위험 플래그 거부, 모의 포트 불변, FIFO/이력 보존, 수동 파일 확인·손상 파일 보호·링크 차단 등을 검사합니다. `scripts/gui_core_ai_connection_smoke.py`는 Linux 가상 Tk GUI에서 미리보기/적용/오류/저장 취소/저장/불러오기/삭제와 네트워크·SQLite·PC 정보 조회 없음 등을 검증합니다. 전체 기존 GUI/단위 테스트도 회귀 검사합니다.

**10단계 사용자 최종 승인과 11~23단계 사용자 PC 실기기 확인은 미완료**이며 공식 로드맵은 9/100입니다. 실제 Windows EXE 빌드/실행, Ollama 모델 설치·실제 연결, OBS 방송은 검증하지 않았습니다.
