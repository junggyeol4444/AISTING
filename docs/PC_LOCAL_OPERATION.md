# 9단계 — PC 로컬 운영 방식 (AISTING v10)

## 확정한 사항

AISTING의 핵심 프로그램은 **Windows PC의 독립 실행형 네이티브 앱**입니다.
GitHub를 서버로 두거나 인터넷 접속·클라우드 계정·API 구독이 있어야만 실행되는 제품이 아닙니다.
다른 서비스를 호스팅 서버로 사용하거나 프로그램 시작과 동시에 외부 방송을 시작하지 않습니다.

| 기능 | 어디에서 동작하는가 | 현재 구현 범위 |
| --- | --- | --- |
| Tkinter 데스크톱 화면 | 내 PC | 소스 GUI 구현, 가상 GUI 검증 |
| 프로그램 설정 JSON | 내 PC 사용자 데이터 폴더 | 읽기/쓰기 구현 |
| SQLite 대화 기억 | 내 PC 사용자 데이터 폴더 | 수동 로컬 AI 사용 시 구현 |
| 모의 시청자 채팅 | 내 PC | 실제 플랫폼 연동 없는 FIFO 연습 |
| Ollama 텍스트 응답 | 같은 PC `127.0.0.1` | 사용자 수동 선택, 이미 설치/실행된 경우에만 |
| Windows 무료 한국어 음성 | 내 PC Windows 기본 시스템 엔진 | 프로그램 측 조회·발화 구현, Windows 실기기 미검증 |
| 아바타 | 내 PC 네이티브 별도 창 | 단순 2D 샘플, 3D 미구현 |
| 실제 플랫폼 채팅/방송 | 플랫폼 인터넷 통신 필요 | 아직 구현되지 않음 |
| GitHub/원격 자동 배포 | 필요 없음 | 코드/패키지에 자동화 설정 없음 |

## 저장 경로

- Windows: `%LOCALAPPDATA%\AISTING\settings.json`,
  `%LOCALAPPDATA%\AISTING\conversation.sqlite3`.
- Linux 등 개발용 환경: `~/.aisting/settings.json`, `~/.aisting/conversation.sqlite3`.
- `.exe`를 옮겨도 운영자 데이터는 실행 파일 안이 아닌 PC 사용자 데이터 위치에 저장됩니다.
  다만 실제 빌드한 Windows EXE에서의 실행은 아직 미검증입니다.
- 설정 저장은 사용자가 **설정 PC에 저장**을 누를 때 발생합니다.
- 대화 기억은 사용자가 로컬 Ollama 연습을 시작·성공적으로 답변한 뒤 생성/수정됩니다.

## PC 로컬 운영 탭의 저장소 점검

1. 앱을 열기만 하면 로컬 경로와 기능 설명만 표시 (네트워크/저장 파일 쓰기 없음).
2. 사용자가 **PC 저장 폴더 점검 (수동)** 버튼을 누르면 앱의 데이터 폴더에
   `aisting-check-*.tmp` 임시 파일 하나를 만들어 읽고 삭제합니다.
3. 기존 `settings.json`, `conversation.sqlite3`를 읽거나 수정하지 않습니다.
4. 검사가 통과해도 **Windows 운영체제, 사용자 PC 사양, GPU, Ollama 설치 상태,
   OBS 연동, EXE 실사용**이 검증되었다는 뜻은 아닙니다.

## 안전 정책

- 앱 실행은 인터넷/플랫폼 로그인/모델 자동 설치/결제를 하지 않습니다.
- 기본 모의 답변은 완전 오프라인입니다.
- 로컬 모델을 명시적으로 선택하여 '모두 답변'을 누르는 경우에만 같은 PC
  `127.0.0.1` Ollama로 통신하며 프록시와 리다이렉트를 허용하지 않습니다.
- 실제 방송 플랫폼 전송은 미구현이며, 선택형 플랫폼 설정만으로는 송출되지 않습니다.
- 예약 실행은 꺼져 있고 GitHub Actions·Git 커밋·병합과 관련된 파일은 포함하지 않습니다.

## 검증 및 한계

- Python 자동 테스트와 `scripts/gui_local_operation_smoke.py` (Tk 가상 화면) 테스트 제공.
- 이 ZIP은 완성 EXE가 아닌 소스 프로젝트이고, 사용자 Windows PC에 설치·접근하지 않았습니다.
- 전체 개발 기준 **10단계 최종 승인**은 운영자 확인 전이며 9단계까지만 완료 처리합니다.
