# v55 / 원본 054단계 — 기본 표정 설정

## 실제 구현

- 기존 `avatar_renderer.AvatarFrame`에 `expression` 기본값 `neutral`을 추가합니다. 기존 생성 방식 및 입 움직임 프레임/깜빡임/배경/캐릭터 이름을 그대로 유지합니다.
- 내장 Tk 2D 샘플에 운영자가 **기본 / 미소 / 놀람 / 걱정** 네 가지 정적 표정을 직접 지정합니다. 이 선택은 AI 대사, 채팅 감정, 실제 목소리·방송과 자동 연결되지 않습니다.
- `기본 표정 설정` 탭에서 현재 본 창과 사용자가 별도로 연 2D 샘플 창의 표정 태그를 동시에 점검합니다. 3D 모드에서 2D 모델이나 표정을 자동 대체하지 않습니다.
- 운영자 확인 후 별도 로컬 `avatar_expression_choice.json`에 기록합니다. 로드는 **수동**이고, 삭제는 두 번 확인해야 합니다. 기존 `settings.json` 구조와 SQLite 기억은 수정하지 않습니다.
- 아바타 선택(미정/2D/3D)을 변경하면 현재 표정이 기본으로 복귀하고, 선택 종류가 일치하지 않는 저장 기록의 불러오기를 차단합니다. 3D 표정 저장은 지원하지 않습니다.
- 저장 JSON은 버전·종류·선택값·항상 false인 미승인 상태 필드만 허용합니다. 잘못된 필드·과대 기록·경로 심볼릭 링크는 거부합니다.

## 범위와 한계

내장 2D 샘플 Canvas 객체에 그리는 **기본 도형 표정**만 개발했습니다. 실제 Live2D/VRM 표정 파라미터 연결, 실물 모델 권리·청취/외관 만족도 평가, Windows 실기기·EXE 테스트, OBS 송출은 **미완료**입니다. 운영자의 승인 없이 AI가 자동으로 표정을 정하지 않습니다. GitHub·외부 서버·프로그램 설치·모델 파일 검색·PC 자동 정보 수집은 하지 않았습니다.

원본 010 최종 승인 및 011 이후 사용자 PC 실제 확인은 별도 승인 대기. 개발 도달 범위만 원본 **054/100**으로 표시합니다. 원본 로드맵의 완료 체크박스를 임의 변경하지 않습니다.
