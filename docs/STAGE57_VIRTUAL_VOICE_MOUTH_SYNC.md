# v57 · 원본 개발 계획 056단계 — 음성과 입 움직임 동기화 (무음 가상 타임라인)

## 구현 및 기획안 근거

원본 `ROADMAP_100.md`의 **056 음성과 입 움직임 동기화**를 다룹니다. 055단계의
`VoiceMouthRehearsal`은 가상 음성 전달 성공 후 입 프레임을 나열했지만, 시간창을
나타내지 않았습니다. 기존 코어를 재사용하여 성공한 대사 청크별 **가상 시작/종료 ms**와
닫힌/열린 입 프레임을 정렬한 `VirtualVoiceMouthSync`를 새로 추가했습니다.

- 채팅은 운영자가 버튼을 눌러 1건씩 모의 전달하며 FIFO/중복 메시지를 보존합니다.
- 가상 음성 길이는 **문자수×운영자 입력 ms(20~500)** 또는 최소 240ms로 생성합니다.
  실제 TTS 음성 길이나 파형 분석 결과가 아닙니다.
- 각 가상 음성 시간창의 0~40% 입 열림 / 40~80% 입 열림 / 80~100% 입 닫힘,
  구간 밖과 마지막 종료시각에는 입 닫힘을 표시합니다. 모의 말끝 표현일 뿐 정확한 립싱크가 아닙니다.
- 시작/종료 시각과 청크의 채팅 고유 순서, 내용, 연속 구간 정합성을 검사합니다.
  중단·오류 청크의 시간창은 생성하지 않습니다. 사용자 클릭 재시도 때에만 추가합니다.
- 별도의 `음성·입 동기화 모의` 탭에서 운영자가 채팅 전달, +100ms 이동,
  0ms 되감기, 임의 가상 시각 조회를 합니다. **타이머 재생·실제 음성 출력·파일 저장은 없습니다.**
- 캐릭터·목소리·표정·아바타·모의 대본·문자별 시간 변경 시 세션을 무효화합니다.
  기존 2D 샘플만 사용하며 3D 모델을 2D로 자동 대체하지 않습니다.

## 유의사항 및 승인 경계

**실제 한국어 TTS 음성 재생 시각/음소와 화면의 일치, 실제 Live2D/VRM 연결,
Windows PC/EXE, 방송·OBS, 운영자 외형·자연스러움 판단은 검증하지 않았습니다.**
가상 ms는 내부 시험용 시간입니다. 010 사용자 최종 승인, 011 이후 사용자 PC 정보 확인,
실제 음성·아바타 사용 허가도 모두 별도 대기입니다.

새 기능은 파일/OS 사양·음성 장치/모델/네트워크/계정/프로그램 설치/GitHub/방송을
조회하거나 실행하지 않습니다. 기존 사용자 설정/SQLite, 기존 문서, 선택형 기능은 보존합니다.
