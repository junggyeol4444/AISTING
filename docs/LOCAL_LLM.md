# 무료 로컬 AI 텍스트 연결 — 코드 구현, 실제 모델 미설치

- ChatPipeline용 **LocalOllamaReplyGenerator** 구현.
- 명시적 실행 시에만 내 PC의 **127.0.0.1:11434/api/chat**로 요청.
- 프록시·리다이렉트 차단, 유료 API·계정 토큰 사용 없음.
- 저장된 캐릭터 설정의 이름/성격/말투와 한국어 출력 지침 반영.
- 기존 FIFO 파이프라인 사용: 채팅을 기본적으로 전부 처리, 인위적 딜레이 없음.
- 로컬 모델 오류 시 채팅 미확인 상태로 남아 재시도 가능.
- 자동 설치/모델 다운로드/구독/실제 방송/음성합성은 **수행하지 않음**.
- 단일 메시지 요청만 지원. 다중 턴 기억과 실제 모델 응답 속도는 아직 검증되지 않았음.

## 나중에 PC를 켰을 때
운영자에게 사양/설치/라이선스/필요 저장공간을 한꺼번에 안내하고 승인받은 뒤
무료 로컬 모델을 준비. 승인된 경우에만 다음 명령을 실행:

\`\`\`bash
python scripts/demo_local_llm.py <사용자가 설치한 무료 모델 이름>
\`\`\`

테스트 코드는 Ollama를 설치하지 않고 가짜 로컬 HTTP 서버로
요청 형식·오류 처리·전체 채팅 FIFO·외부 요청 차단을 검증함.

예약 작업은 계속 꺼져 있음.
