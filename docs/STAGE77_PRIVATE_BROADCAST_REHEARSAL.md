# v77 · 원본 076 비공개 방송 테스트 — 오프라인 절차 리허설

## 목표와 분리 원칙

- 원본 `docs/ROADMAP_100.md` 076 항목은 **비공개 방송 테스트**이지만, 외부 방송 송출·OBS 연결·계정 접근·스트림 키·Windows PC 사용은 승인되지 않았습니다. **실제 비공개 방송 테스트는 실행하지 않았고 대기**입니다.
- 본 단계에서 승인 없이 구현한 범위는 이전 원본 071~075의 **로컬 미리보기·가상 음성 문자·설정 음량 점검·메모리 송출 초안**만 재사용하는 **수동 오프라인 절차 리허설**입니다.
- '모의 절차 통과'라는 결과는 플랫폼 공개 범위/비공개 방송 설정/실제 시청자 접근 제한이나 송출 품질을 보증하지 않습니다.

## 사용법

`방송 화면 구성 미리보기` 탭에서 ① 현재 선택으로 미리보기 갱신 → ② 음량·방송 화면 점검 (오프라인) → ③ 송출 설정 초안 연결 (오프라인) → ④ **비공개 방송 절차 모의 시험 (오프라인·송출 불가)** 버튼 순으로 수동 실행합니다. 시험 결과는 화면의 읽기 전용 문장으로 표시하며 저장하지 않습니다.

아래의 **5개 메모리 상 단계**만 실행합니다:

1. 사전 점검: 현재 640×360 Canvas의 태그, 선택 장면·음량·가상 음성 상태와 기존 074 점검/075 설정 초안의 일치 검사
2. 가상 시작: 외부 출력 없는 메모리 내 이벤트
3. 가상 화면·음성 확인: 이미 만들어진 가상 화면 태그/무음 문자 연결 상태만 확인
4. 가상 종료: 외부 출력 없는 메모리 내 이벤트
5. 송출 비활성 확인: 기존 출력 초안의 OBS/영상/음성/계정/목적지가 모두 미연결임을 확인

설정이 바뀌거나 미리보기가 새로 그려지면 076 결과를 즉시 무효화합니다. 075 초안을 다시 준비하면 반드시 076 시험을 새로 해야 합니다. 코드의 `inject_failure_at`은 자동 단위 시험에서만 사용하는 모의 장애 위치이며 외부 오류를 유발하지 않습니다.
