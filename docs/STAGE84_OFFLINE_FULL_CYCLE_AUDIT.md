# v84 · 원본 083 시작부터 종료까지 자동 진행 테스트 — 오프라인 수동 통합 감사

## 원본 계획과 허용된 구현의 차이

원본 4부는 방송 일정 판단 → 공지 → OBS 실제 시작 → AI 코어/채팅/음성/아바타 방송 진행 → 종료 시점 판단 → 자연스러운 종료 멘트 → OBS 종료 및 종료 공지로 구성된다. **이 단계에서 실제 공지·OBS·플랫폼·음성·방송·사용자 PC 조작은 모두 금지/미승인**이므로 실제 전체 자동 진행 테스트를 완료했다고 주장할 수 없다. 이번 v84는 기존 081/082 일정·시작 판정, 078 시간 규칙, 079 가상 종료 문구를 서로 연결한 **수동·메모리·무시간 대기 오프라인 통합 감사**다.

## 실제 구현

- `src/ai_broadcaster/offline_full_cycle_audit.py`는 별도 가상 시작 제어기를 생성하고 운영자 입력 KST 날짜·시각이 로컬 초안과 일치하는지/모든 금지 플래그가 `False`인지 확인한다.
- 가상 시작→중복 시작 차단→직접 주입한 가상 경과시간 0/최소 직전/최소/최대 직전/최대 판정→예고→인사→가상 종료→중복 종료 및 같은 일정 재실행 차단의 **14개 연결 검사**를 실행한다.
- 각 검사 결과는 불변 보고서에 저장한다. 어느 검사라도 실패/예외/잘못된 상태가 발생하면 즉시 미통과로 중단한다. 실제 종료 성공으로 바꾸지 않는다.
- '방송 시작 일정 초안' 탭의 `083 시작부터 종료까지 통합 모의 감사` 수동 버튼으로 실행한다. 기존 082 가상 세션·설정·파일에는 접근하지 않으며, 입력/일정 수정 시 이전 결과를 무효화한다.
- 단위 테스트에서 시작 컨트롤러/종료 상태 기계를 일부러 잘못 동작시키면 감사 미통과가 나오는지 확인한다. 위험한 설정 플래그, 날짜 불일치, 표시 실패, 상태 변조, 예외 등을 검사한다.

## 중요한 미구현/미검증

현재 초안은 사용자가 수동 입력한 시간에서 순간적으로 가상 방송 전체를 통과하며 **실제 1~3시간을 기다리지도 않음**. 백그라운드 타이머, PC 시계 감시, 공지, 시청자 채팅, TTS, Live2D·VRM, OBS, 스트림 목적지, 플랫폼 비공개 여부, 실기기에서의 종료와 복구, Windows EXE는 이 감사의 검증 대상이 아니다. 다른 단계에서 존재하는 모의 채팅/화면을 이번 완전한 실제 실시간 파이프라인으로 오인하면 안 된다. 자동화/권한·승인/계정 연결은 이번 코드에서 생성하지 않는다.
