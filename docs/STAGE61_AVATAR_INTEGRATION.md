## 기획안과 범위

원본 `docs/ORIGINAL_PLAN.txt`의 두뇌→음성→아바타 연결 비전 및 원본 `docs/ROADMAP_100.md` 060 `캐릭터 전체 작동 확인`을 기준으로 **기존 내장 2D 샘플**의 모의 기능만 통합 검증했습니다. 이 결과는 실제 방송인의 완성이나 운영자 승인에 해당하지 않습니다.

## 구현

- `src/ai_broadcaster/avatar_integration_review.py`의 `audit_avatar_integration`은 기존 054 표정·057 움직임·058 배치·055~056 가상 음성/입 시각 정렬·059 가속 반복 실행 코드를 재사용합니다.
- 현재 사용자 선택을 변경하거나 저장하지 않고, 내장 2D 4표정 × 대기/발화/눈 깜빡임의 **16개 구조 프레임**을 실제 Tk Canvas에 렌더링·검사합니다. 사용자 지정 이름·표정·가상 배경·위치·크기를 유지합니다.
- **무음 시험용 음성 식별자**를 별도로 사용해 모의 채팅 2건을 전달합니다. 두 번째 채팅은 1회 강제 중단하며, 음성 구간 추가 없이 미처리 상태가 보존되는지 확인한 다음 **시험 내부에서 명시적으로 한 번 재개**합니다. 실제 음성 재생·선택된 Windows 음성 설치 여부·발음은 검사하지 않습니다.
- 생성된 가상 음성 구간 시작/종료 직전/종료 후의 입·표정·배경·이름·배치 Canvas 구조를 검사합니다. 가상 문자 길이로 만든 시간표이므로 실제 음소·파형 립싱크가 아닙니다.
- 기존 059 가속 모의 **1시간/3,600프레임**, 12개 체크포인트 제한, 실제 Tk Canvas 60회 다시 그리기를 통합 검사에 재사용합니다. 실제 한 시간 동안 실행하지 않습니다.
- 사용자가 **2D + Windows 무료 음성 방식**을 선택한 경우에만 무음 통합 검사를 수동 실행합니다. 미정·3D·미지원 음성은 실패로 처리하며 2D/음성으로 임의 대체하지 않습니다.
- 검사 성공·실패/예외 여부와 관계없이 현재 선택된 **대기 프레임으로 복원**합니다. GUI에서 캐릭터·표정·아바타·음성 방식/속도/음량·배치·배경 변경 시 이전 검사 결과를 무효화합니다.
- 계정, 외부 서버, 모델, OBS, 파일 저장, 마이크, 실제 TTS·음성 장치, 사용자 PC 정보 조회는 호출하지 않습니다.
