# AISTING 8단계 — 아바타 형태 선택 (완전 로컬)

이 단계는 운영자가 개발 전에 2D 또는 3D를 **고정해서 정하는 단계가 아니라**,
AISTING Windows 프로그램 안에서 **미정 / 2D / 3D**를 선택하고 언제든 변경·저장하는 단계다.

## 구현된 동작

- **미정**: 기본 설정. 아바타 형태를 확정하지 않는다. 기존 Tkinter 2D 그림은
  **선택과 무관한 예시**로만 표시한다.
- **2D**: Tkinter 캔버스로 제작한 무료 샘플을 프로그램 탭 및 운영자가 직접 여는 별도 창에서 확인한다.
  PC 음성 상태에 따른 단순 입 움직임 테스트가 가능하다. Live2D 모델·정밀 립싱크가 아니다.
- **3D(VRM)**: 3D라는 선택을 PC 로컬 설정에 **기록**한다. 실제 VRM 모델·3D 렌더러는 아직
  없으므로 안내 화면만 표시하고, **2D 샘플 창 열기는 비활성화**한다.
  2D 샘플 별도 창이 열려 있었다면 3D 전환 시 그 창만 닫는다.
- 미정 또는 2D로 돌아오면 기존 무료 2D 샘플 기능을 다시 이용할 수 있다.
- 프로그램이 다시 실행되면 이전에 저장한 선택을 복원한다. 기존 v08 설정 JSON 구조는 그대로 사용하므로
  설정 마이그레이션이나 데이터 삭제가 필요 없다.
- 아바타 종류 변경만으로 OBS 실행·방송 송출·외부 계정 접속·모델 다운로드·유료 구매가 시작되지 않는다.

## 향후 별도로 필요한 작업

정식 Live2D 파일, 3D VRM 파일, 렌더링 환경, 음성·표정 정확도, OBS 실제 창 캡처 및
방송 연결은 모두 **미구현** 또는 **실기기 미검증** 상태다. 모델 파일의 권리 및
추가 프로그램 설치 여부는 사용자가 PC를 켜고 별도로 승인해야 한다.

`python -m unittest discover -s tests -v`

`python scripts/gui_avatar_selection_smoke.py` (Windows/Tkinter 또는 Linux Xvfb)
