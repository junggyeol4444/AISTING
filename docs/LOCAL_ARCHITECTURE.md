# AISTING — PC 로컬 우선 실행 설계 (오프라인 개발본 v10)

## 결정된 구조

**실행 장소는 운영자 Windows PC입니다.** 프로그램 창은 `tkinter`로 실행되며 웹 브라우저·GitHub·외부 서버를 통해 띄우지 않습니다. 사용자 지시가 없는 자동 설치, 결제, 방송 시작, 원격 업로드, 예약 실행은 수행하지 않습니다.

| 구성 | 실행 위치 및 외부 의존성 |
| --- | --- |
| AISTING 설정 UI | 내 Windows PC. 인터넷 불필요 |
| 무료 모의 시청자 채팅 / FIFO 큐 | 내 PC. 인터넷 불필요 |
| 대화 기억 SQLite | 내 PC 사용자 저장소. 인터넷 불필요 |
| 기본 2D 샘플 아바타 | 내 PC `tkinter` Canvas 및 별도 운영체제 창. 인터넷 불필요 |
| Windows 한국어 음성 | 내 PC에서 설치된 Windows 시스템 음성 엔진. 인터넷 불필요 |
| 선택적 Ollama AI 대답 | 내 PC에서 이미 실행 중인 **로컬** Ollama에 `127.0.0.1`로만 요청. 외부 호스트 요청 금지 |
| 실제 치지직/유튜브/트위치 방송 | 현재 미구현. 구현 시 플랫폼과의 인터넷 통신 필요 |
| OBS/정식 2D·3D 아바타 | 이 오프라인 개발본에는 아직 미구현 |

`127.0.0.1`은 GitHub가 아니라 **같은 PC 안의 프로그램끼리 통신하는 루프백 주소**입니다. 기본 모의 응답과 Windows 음성은 이 연결조차 필요 없습니다.

## GitHub/서버/자동화 제거 기준

- 프로젝트 ZIP에 `.git/`, `.github/`, Actions 워크플로, 배포 자동화 파일이 없습니다.
- 프로그램은 GitHub 상태, 클라우드 컴퓨터, ChatGPT 서비스에 로그인하거나 접근하지 않습니다.
- EXE를 만드는 작업은 Windows에서 사용자가 명시적으로 `build_exe_windows.bat`를 실행하는 **수동 빌드**입니다. 빌드 도구가 없으면 다운로드 없이 종료합니다.
- **GitHub가 사라져도** PC에 이미 저장된 실행 파일, 설정, 음성, 2D 데모, 로컬 모델을 이용한 처리에는 영향이 없습니다.
- 다만 실제 외부 플랫폼 방송 기능을 나중에 구현하면 방송 플랫폼의 네트워크 이용 자체는 필요합니다.

## 현재 한계

이 작업은 대화에서 이용 가능한 초기 소스를 기반으로 한 **별도 오프라인 개발본**입니다. 이전 원격 저장소의 모든 기능을 완전히 복원한 것으로 표시하지 않습니다. Windows PC에서 직접 오디오가 출력되는지는 **실기기 검증 전**입니다. `.exe` 자체도 아직 이 Linux 작업 환경에서는 만들지 않았고 소스만 전달합니다.

공식 로드맵 3/100: 방송 플랫폼은 치지직·유튜브·트위치 0~3개를 프로그램 안에서 직접 선택·변경하도록 확정됐으며, 특정 플랫폼의 사전 선택은 요구하지 않습니다. 실제 플랫폼 로그인·방송 송출은 구현 전 별도 승인 사항입니다.

## v03 추가: 아바타 별도 창

Tkinter `Toplevel`로 **AISTING.exe 본 창과 독립된 아바타 창**을 그립니다.
동일 프레임·동일 로컬 음성 활동 상태를 사용하지만 OBS 또는 플랫폼과는 통신하지 않습니다.
운영자가 직접 OBS 창 캡처를 선택할 수 있는 기반만 제공합니다.

## v10: 로컬 운영 점검

- `src/ai_broadcaster/local_runtime.py`: 실제 서버에 연결하지 않고 PC 로컬 전용 실행 구성을 보고.
- 데이터는 Windows의 `LOCALAPPDATA\AISTING` 또는 다른 OS에서는 `~/.aisting`.
  설치된 `.exe` 위치나 GitHub URL은 운영 데이터 경로가 아닙니다.
- PC 저장 폴더 점검은 수동 클릭 이후 전용 임시 파일만 작성하고 검사 즉시 삭제.
  기존 설정 JSON·SQLite 기록에 쓰거나 해당 파일을 열지 않습니다.
- 운영자의 PC 사양 조회나 로컬 모델/OBS 실사용 진단은 시행하지 않았습니다.
- 원격 저장소나 GitHub Actions에 EXE 실행 의존성이 없습니다. 다만 제작용 `.bat`는
  Windows에 PyInstaller가 **이미 설치된 경우**에만 수동으로 `.exe`를 생성합니다.
- 운영 방식 자체는 확정(9단계). 실제 방송 및 Windows 실기기 통합 테스트는 미완료.
