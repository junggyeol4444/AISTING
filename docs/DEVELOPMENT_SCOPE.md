# 13단계 준비 — 현재 PC 기준 개발 범위 검토

`개발 범위 검토` 탭의 버튼을 누르면 `OS 확인 준비` 및 `PC 사양 입력` 탭에 **현재 표시된 수동 입력값**으로 참고 범위표를 만듭니다. 두 탭에서 별도 불러오기 버튼을 누르지 않았다면 과거 입력 기록을 자동으로 읽지 않습니다. 결과는 메모리와 화면에만 표시하며 저장하지 않습니다.

## 검토 항목

1. 현재 소스에서 구현된 설정·모의 채팅·SQLite 기억·2D 샘플 아바타와 실제 Windows PC 동작 검증을 구분합니다.
2. Windows 시스템 한국어 음성은 설치된 목소리 여부 확인이 필요함을 표시합니다.
3. 로컬 Ollama 연결 코드는 선택형이지만 모델 설치, 모델별 메모리 요구량, 속도는 확인하지 않았음을 표시합니다.
4. EXE 빌드 스크립트가 있어도 실제 Windows x64 빌드·실행 검증은 별도임을 표시합니다.
5. 실제 3D VRM, 플랫폼 실시간 채팅 수집, OBS 송출은 아직 미구현이라고 표시합니다.
6. 직접 입력한 Windows 10/11 x64는 **빌드 검토 후보**로만 표시하며 PC 호환성 검증 통과로 판정하지 않습니다. 기타/미입력 OS는 검토 필요로 표시합니다.

임의의 RAM/VRAM 임계치나 FPS/모델 처리 속도 예측을 만들어내지 않습니다. 입력이 충분하더라도 `machine_verified`, `performance_verified`, `windows_exe_verified`는 모두 `False`입니다.

**제한:** 10단계 운영자 최종 승인, 11단계 실제 OS 확인, 12단계 실제 CPU/RAM/GPU 확인, 13단계 사용자 PC 실기기 범위 검증은 모두 대기입니다. 이 화면은 사용자 확인이 필요한 단계를 자동 승인하지 않습니다. 다른 기능 개발은 대기 항목 때문에 중단하지 않습니다.

검증 코드: `tests/test_development_scope.py`, `scripts/gui_development_scope_smoke.py`.
