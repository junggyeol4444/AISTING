# 6단계 성격·말투 초안 — 운영자가 나중에도 자유롭게 변경

이 초안은 기본 페르소나/자유 입력 방식을 유지한다.

* 세 가지 참고 예시(차분한 설명형, 활기찬 소통형, 담백한 게임형)는 단지 **선택 가능한 초기 문구**이며 아무거나 미리 확정하지 않는다.
* '선택한 초안 적용'을 클릭했을 때만 성격과 말투를 덮어쓰고 **이름은 절대로 바꾸지 않는다**.
* '직접 만들기' 모드에서는 세 항목을 계속 자유 편집할 수 있다. 미리보기는 AI에 입력할 로컬 문자열을 화면에 보여줄 뿐, 응답 품질 시험이 아니다.
* 기본 캐릭터로 바꿔도 직접 입력한 초안은 로컬 설정에 남는다.
* 프로그램 기본 모의 답변은 어떤 예시를 사용하든 네트워크 연결을 하지 않는다.
* 실행 중인 무료 Ollama 모델을 사용자가 수동 선택했을 때에만 저장된 성격·말투가 시스템 지침에 반영된다.
* PC 설치, 외부 계정 연결, 방송 송출, 결제, 예약, 원격 코드 저장은 수행하지 않는다.

검증: Python 단위 테스트, Xvfb/Tkinter GUI smoke test. Windows EXE 실기기 음성/방송 환경 검증은 아직 없다.

* 설정 항목이 화면보다 길어도 세로 스크롤을 통해 **설정 PC에 저장** 버튼에 접근할 수 있다.
