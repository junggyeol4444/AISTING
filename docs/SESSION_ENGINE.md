# 플랫폼 독립적 모의 방송 엔진 — 첫 구현

`src/ai_broadcaster/session.py`는 실제 방송 시스템을 호출하지 않는 **순수한 상태 머신**이다.

## 구현 범위

- 상태: `offline → live(내부 모의 상태) → closing → offline`.
- 채팅: 받은 메시지를 FIFO 대기열에 누락 없이 저장, 등록된 모든 메시지를 입력 순서로 꺼낸다.
- 서로 다른 시청자가 같은 내용으로 보낸 채팅도 두 개 모두 보존한다.
- 인위적 채팅 응답 지연 없음. API/LLM 호출, 음성 출력은 **아직 구현되지 않았음**.
- 종료: 운영자가 지정한 최대 방송 시간을 설정한 경우에만 마무리를 요청한다.
- 마무리: 인사를 마쳤다는 신호를 받아야 내부 상태를 종료로 변경한다.
- 모든 이벤트는 내부 문자열 결과일 뿐 외부 OBS/WebSocket/게시 서비스를 실행하지 않는다.

## 테스트 실행

```sh
python -m unittest discover -s tests -v
python scripts/demo_session.py
```

## 한계

이 모듈은 **공통 방송 엔진의 기반**이다. 실제 방송을 송출하거나 AI가 채팅에 말로 대답하는 버전이 아니다.
사용자 PC에 아무 프로그램도 설치하거나 계정 연결을 시도하지 않는다.

다음 개발에서 필요한 것은 운영자 방송 플랫폼 선택, 페르소나·음성 등 승인 및 실시간 채팅/TTS/OBS 외부 연동이다.
