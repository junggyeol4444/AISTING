## 기획안·기존 단계 준수

## 신규 기능: 독립된 수동 통합 시험

`채팅 소통 통합 모의 검증` 탭에서 운영자가 버튼을 누르면 선택된 플랫폼 1~3개를 사용하여 **현재 앱 채팅 세션과 별개인** 임시 메모리 시나리오를 한 번 실행합니다. 플랫폼을 선택하지 않았다면 실행을 거부하며 임의로 선택하지 않습니다. 기존 연결·수신함·FIFO·모의 응답·설정·사용자 데이터는 변경하지 않습니다.

기존 `OfflinePlatformChatConnector`, `OfflineChatReceiveBuffer`, `OfflineChatOrder`, `OfflineChatReactions`, `OfflineChatConnectionRecovery`를 조립해 6개 모의 메시지를 처리합니다. 서로 다른 가상 시청자, 동일 내용 중복, 전역 FIFO, 동일 플랫폼·닉네임별 이전 성공 답변 맥락, 의도적 응답 실패와 수동 재개, 가상 연결 장애와 수신 차단, 가상 핸드셰이크 실패, 명시적 재연결/재준비, 장애 전 기록 보존, 이후 추가 수신, 최종 6/6 응답을 확인합니다. 15개 점검 항목 중 하나라도 실패하면 `passed=False`이며 부분 성공을 전체 성공으로 보고하지 않습니다.

의도적 실패→복구 동작은 **오직 사용자가 시작한 유한한 시험 시나리오 내부**에서 실행됩니다. 실제 운영 세션에 대한 자동 재시도, 백그라운드 폴링, 고의 지연, 자동 실행은 없습니다. 시험에서 실패한 채팅을 버리거나 임의로 선별하지 않습니다. 플랫폼 선택 변경 시 이전 GUI 시험 결과를 무효화합니다.
