# v37 개발: 원본 로드맵 036 자연스러운 응답 속도 확인 — 오프라인 계측 준비

## 정확한 범위

기획안은 **모든 채팅에 자연스러운 속도로 반응**하며, 인위적 대기나 채팅 선별을 기본값으로 두지 않는다고 정한다. 그러나 **어떤 속도가 자연스러운지는 운영자가 최종 판단**한다. 따라서 임의 지연과 합격 기준을 구현하지 않는다.

이번 구현은 `config/roadmap.json`과 `docs/ROADMAP_100.md` 원본 항목 036 '자연스러운 응답 속도 확인'을 위한 **모의 코어 응답 처리 시간의 수동 계측**이다. 036 단계의 실제 AI 응답 속도·Windows PC 동작·음성 발화 속도·방송 체감 자연스러움은 **완료하지 않았다**.

## 변경사항

- `src/ai_broadcaster/response_speed_test.py`: 최대 30건의 임의 편집 채팅을 독립 `OfflineCoreSession`에서 모의 처리. 각 채팅을 처리하는 구간만 고해상도 단조 시계(`time.perf_counter_ns`)로 수동 계측. 응답별 ms, 중앙값, 최소·최대, P95(최근접 순위), 유효 표본 합계를 제공한다. 측정 시작/종료에 실패하거나 시간이 역전되면 실패 판정, 포트 오류 시 대기열 보존·자동 재시도 금지, 오류 원문의 민감 문자열 미노출.
- `src/ai_broadcaster/desktop.py`: '응답 속도 관찰' GUI 탭. 대본 편집·수동 실행·예시 복원·결과 조회. 앱 실행·탭 진입만으로는 측정하지 않는다.
- `tests/test_response_speed_test.py`: 결과 집계, 타이머 주입, 0ns, P95, 중복/FIFO/8턴 맥락, 실패/민감정보 보호, 시계 오류, 입력 한도, 30건, 설정 불변성·비접속·비지연, 세션 독립성 테스트 13개.
- `scripts/gui_response_speed_smoke.py`: 가상 화면에서 탭 이동, 모의 시험, 대본 수정, 입력 오류, 예시 복원, 무저장 검사.

## 해석상의 주의

- **실제 AI 모델 호출 시간, 모델 토큰 생성, 음성(TTS) 합성·출력, 아바타, UI 리프레시, 외부 채팅 전송, 방송 체감 지연을 측정하지 않는다.**
- 개별 측정은 동기 모의 코어 함수 호출 구간이며 과제 스케줄링·CPU 간섭의 영향을 받는다. 타이밍 값은 실행 환경별로 달라서 임계값으로 합불 판정하지 않는다.
- 모의 답변의 처리량과 실제 AI 모델 품질을 연결해서 해석하면 안 된다.
- 설정·SQLite·기획안·금기/반응 방향을 읽거나 쓰지 않는다(앱은 원래 앱 기동 시 사용자 설정 읽기만 수행). 운영자가 단계를 열어 **측정 버튼을 누를 때만** 임시 메모리 세션을 실행한다.
- **PC 사양/OS 조회, 설치, 외부 연결, 계정, OBS, 방송, GitHub 작업 없음**.

## 검증 방법

```bash
PYTHONPATH=src python -m unittest discover -s tests -q
PYTHONPATH=src xvfb-run -a python scripts/gui_response_speed_smoke.py
```

Linux 가상 화면에서의 GUI 실행은 Windows 실기기 검증을 대체하지 않는다. 10단계 최종 승인과 11단계 이후 사용자 PC 실제 정보 확인은 계속 `pending`이다. 개발 작업 진행 범위 v37 및 로드맵 036의 오프라인 계측 구현은 사용자 승인 완료·실제 AI 자연스러움 검증과 분리하여 기록한다.
