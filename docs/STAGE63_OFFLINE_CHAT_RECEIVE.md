## 구현 범위

- `src/ai_broadcaster/offline_chat_receiver.py`: 사용자 버튼으로 준비한 061의 가상 연결에만 **직접 입력한 모의 채팅 한 건**을 접수한다.
- 플랫폼·닉네임·텍스트 형식 및 길이 검증, 선택되지 않은 플랫폼 차단, 500건 메모리 상한 도달 시 명시적 거부(기존 500건 보존), 동일 내용 중복 접수 유지.
- 연결 해제/플랫폼 선택 변경 시 수신 준비 상태만 무효화하고 **이미 접수한 모의 채팅은 보존**한다. 새로운 가상 연결 후 수동 재준비하면 기존 기록 뒤에 추가된다.
- `desktop.py`의 `채팅 수신 모의` 탭: 가상 수신 준비·플랫폼 선택·직접 입력·수동 1건 접수·최근 10건 보기. 원본 `방송 설정`이나 061 탭, 기존 사용자 설정/SQLite 기록을 변경하지 않는다.
- 모의 메시지는 현재 프로그램의 메모리에만 있고 종료 시 사라진다. 실제 플랫폼 메시지 수신 **0건**. 소켓·웹소켓·HTTP·타이머·백그라운드 리스너·외부 AI·OBS·저장/내보내기·자동 응답 없음.
