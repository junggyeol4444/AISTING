# AI 대사 → 무료 한국어 음성 통합 (개발용 EXE)

- AI 대화 테스트 탭에 설치된 Windows 한국어 음성 찾기, 목소리 선택, 읽기, 중지 버튼 추가.
- 새 AI 답변이 오면 '마지막 AI 답변 읽기' 버튼으로 수동 재생 가능.
- 'AI 답변 생성 후 자동으로 읽기'는 기본값 **꺼짐**. 사용자가 직접 켜야 재생.
- AI 답변을 원문 순서대로 최대 600자씩 분할해 System.Speech로 재생, 최대 6,000자 지원.
- 음성 합성 작업은 백그라운드 UI 스레드에서 실행해 프로그램 화면이 멈추지 않게 함.
- 중지 시 새 음성 구간을 추가로 읽지 않음, 오디오 중복 재생 차단.
- 음성 실패 시에도 채팅 응답·대화 기억을 수정하거나 재송신하지 않음.
- 사용자가 수동으로 텍스트 전송한 **PC의 로컬 Ollama 대화 테스트**에서만 자동 읽기 가능.
- OBS 방송 송출, 음성 립싱크, 실제 플랫폼 실시간 채팅과는 아직 연결되지 않음.

**무료 조건**: PC에 이미 설치된 Windows 한국어 음성/로컬 모델만 사용. 다운로드/유료 API/외부 계정 로그인은 시작하지 않음.
사용자 PC에서 음성 장치와 소리의 자연스러움은 별도 실사용 확인 필요.
예약 작업 중지 유지.
