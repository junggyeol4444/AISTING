# 무료 한국어 Windows 음성 — 개발 단계 v02

## 구현

- EXE용 `tkinter` 탭 **무료 한국어 음성**에서 운영자가 누른 경우에만 설치된 `ko-KR` 음성 목록 조회.
- Windows PowerShell 및 Windows 기본 `.NET System.Speech`만 사용. 네트워크 접속, 유료 API, 패키지 설치 없음.
- **문장 미리 듣기**, **마지막 AI 답변 듣기**, **소리 중지**.
- **새 답변 자동 읽기** 초기 **꺼짐**. 사용자가 체크해야 동작하며, 텍스트 답변은 받은 순서대로 음성 대기열에 넣어 읽음.
- 자동 읽기 중지 시 아직 읽지 않은 *음성 대기열*을 비우지만, 채팅 답변/기억은 건드리지 않음.
- 600자 초과 답변은 최대 600자 단위로 나눠 원문 그대로 읽음. 채팅 메시지를 인위적으로 생략하지 않음.
- 실제 음성 프로세스가 동작하는 동안 2D 아바타 **샘플**의 입 애니메이션이 작동. 실제 음소별 정밀 립싱크와는 다름.
- 사용자 문장은 PowerShell 명령 문자열에 이어 붙이지 않고 `stdin` UTF-8 JSON 데이터로 전달. 음성 이름은 설치된 `ko-KR` 음성에 대해 다시 검사.
- Windows에서 한국어 시스템 음성이 없으면 안내만 하고 자동 설치하지 않음.

## 실행 준비

Windows PC에 Python 3.11+가 이미 준비되어 있으면 `run_windows.bat` 실행. PyInstaller가 이미 설치돼 있다면 `build_exe_windows.bat`를 **운영자가 직접 실행해** EXE로 묶을 수 있습니다. 자동 다운로드나 설치는 없습니다.

## 테스트

- 모의 Windows 음성 프로세스 기반 재생/인증된 음성 목록/오류/중단/한글·명령 문자열 안전성 검증.
- GUI의 자동 재생 기본 OFF와 FIFO 4건 모의 테스트.
- 위 테스트는 실제 Windows 음성 설치/스피커 성능을 확인한 것은 아님.

## 미구현

음성의 OBS 출력, 실제 방송 자동 발화/플랫폼 채팅 연결, 음소·파형 기반 립싱크, 음성 복제. 운영자 PC와 방송 플랫폼 승인이 필요한 작업은 시작하지 않습니다.
