# 2단계 — 반드시 구현할 핵심 기능 정리

원본 기획안 2·4·5·6·7부에 근거함. 구조화 목록은 `config/features.json`.

## 반드시 구현할 것
1. **두뇌/페르소나** — 한국어 LLM 대화와 캐릭터 일관성.
2. **실시간 채팅** — 모든 채팅에 기본적으로 반응. 인위적 딜레이/선별 반응 없음.
3. **한국어 음성(TTS)** — 사용 허락을 받은 목소리로 출력.
4. **아바타/립싱크** — 캐릭터가 표시되고 말에 따라 입 움직임.
5. **방송 송출** — OBS 화면/오디오 송출과 시작·종료 제어.
6. **방송 흐름 자동화** — 일정 확인, 시작, 진행, 종료 조건 판단, 자연스러운 인사.
7. **공지 자동화** — 승인된 디스코드/카페 채널의 시작·종료 안내.
8. **기억/로그** — 이전 대화/방송 기록 관리.
9. **안정성/운영** — 오류·자동 재시작·비용/토큰 관리.

## 운영자 선택 후 구현
- 플랫폼, 콘셉트, 페르소나, 목소리/동의, 아바타/서버, LLM/예산.
- 게임/화면 인식, RVC, 시작·종료 랜덤 변주, 채팅 저조 종료는 선택 기능.

## 완료 판단
- 필수 9개/선택 5개가 구조화된 JSON으로 구분됨.
- 운영자 승인 전 금지 항목이 기록됨.
- 코드 검증에서 필수 기능 누락/선택 항목 강제 활성화가 없어야 함.

**이 문서는 구현 완료를 뜻하지 않습니다.** 개발 범위 확정에 필요한 기능 목록만 작성한 결과입니다.
