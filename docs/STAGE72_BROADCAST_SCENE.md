# AISTING v72 · 원본 071 방송 송출 화면 구성 — 오프라인 Canvas 초안

## 기존 기획·로드맵과의 관계

원본 `docs/ORIGINAL_PLAN.txt`의 플랫폼 자유 선택, 수다/게임/둘 다/미선택, 캐릭터·목소리·아바타 선택 및 운영자 판단 원칙을 유지합니다. `docs/ROADMAP_100.md` 071 및 `config/roadmap.json` 010/071은 사용자 승인/실방송 검증 전 `pending`입니다. **코드 개발 도달 71/100**은 사용자 최종 승인·Windows 검증·방송 완성을 의미하지 않습니다.

## 신규 구현

- `방송 화면 구성 미리보기` 탭에서 **운영자가 버튼을 눌렀을 때만** 로컬 Tk Canvas 640×360 (16:9)에 가상 방송 장면 구성안을 그립니다. 실시간 렌더링/녹화/방송이 아닙니다.
- 기존 `offline_settings.py` 선택형 플랫폼(0~3개), 콘텐츠(미정·수다·게임·둘 다), 목소리 방식, 캐릭터 이름, 아바타(미정·2D·3D) 및 058단계 `AvatarLayout`을 **읽기 전용으로 재사용**합니다. 기존 `draw_layout_preview()`를 호출하며 별도 아바타 렌더러를 중복 구현하지 않습니다.
- 콘텐츠는 실제 게임 캡처나 실시간 채팅이 아닌 명시적 자리표시자입니다. 3D/미정 아바타는 자리표시자만 보이고 2D로 몰래 바꾸지 않습니다. 오디오 경로는 미연결이라고 표시합니다.
- 운영자는 임시 제목/채팅 UI 표시를 켜고 끌 수 있습니다. 사용자 선택·배치·표정 변경 시 기존 미리보기 결과가 즉시 무효화되며, 다시 버튼을 눌러야 갱신됩니다.
- 기존 2D 아바타 배치가 콘텐츠 영역과 겹치면 **경고만 표시**하며 운영자의 위치 선택을 임의 수정하지 않습니다. 플랫폼 미선택도 그대로 보존합니다.
- 장면 구성안은 메모리에만 존재하며 설정·기억·배치 파일을 읽거나 저장/변경하지 않습니다. 실제 화면 캡처, OBS/스트리밍 연결, 마이크·스피커, 계정·네트워크·외부 API, 설치, 사용자 PC 정보·음성 수집, 자동 재시도/타이머는 추가하지 않았습니다.

실제 방송 송출 화면 구성/OBS 장면 소스/화면 캡처, 실제 3D 모델, 음성 믹싱, 실시간 채팅 오버레이, Windows 실기기 및 EXE, 설치·권리·음성/아바타 자연스러움 평가, 원본 010 사용자 최종 승인은 **검증/구현하지 않았습니다**. 후속 원본 072 `아바타 화면 연결`은 오프라인 범위에서만 검토합니다.
