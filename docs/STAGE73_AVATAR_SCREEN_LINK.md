# v73 · 원본 072 아바타 화면 연결 (오프라인 부분 구현)

원본 기획안, 100단계 로드맵, README, v72 개발/검증 로그 확인 후 진행. 기존 071 방송 장면 구성과 058 아바타 렌더러/배치만 재사용합니다.

운영자 수동 버튼으로 기존 2D 아바타 샘플을 640×360 오프라인 Canvas 장면에 표시하고 실제 Canvas 태그를 검사합니다. 3D/미정은 연결하지 않고 자리표시자 유지, 2D 자동 대체 금지. 외부 화면 캡처, OBS, 방송, 계정, 네트워크, 장치 조회, 파일 저장은 없습니다.

검증: 전체 unittest 1365건 통과; 기존 방송 장면 GUI 스모크 및 신규 Tk Canvas 2D/3D 스모크 통과; Python compileall 통과. Linux Xvfb 검증이며 Windows/EXE/실제 아바타·방송 검증이 아닙니다. 원본 072 사용자 승인 및 실기기 검증 pending 유지.
