# AISTING v85 — 원본 084 방송 전 공지 문구 생성 (오프라인 검토 초안)

## 원본 기획안과 범위

`docs/ORIGINAL_PLAN.txt` 5부 공지 자동화 중 방송 시작 전 캐릭터 말투·방송 맥락 반영 및 운영자 선택이라는 취지를 보존한다. 원본 로드맵 084는 '방송 전 공지 문구 생성'이다. 085 디스코드 연결, 086 자동 게시, 088 자동 변주·운영자 설정 적용은 **아직 구현하지 않는다**.

현재 계정 연결/외부 서버/API/유료 결제/승인 없는 OBS를 모두 금지하므로, 기존 저장 설정의 캐릭터 이름·방송 유형·선택 플랫폼 및 운영자가 입력한 KST 시작 시각과 주제를 이용해 **규칙 기반 텍스트 미리보기**만 생성한다. 실제 LLM 작성으로 가장하지 않는다. 없는 방송 URL을 만들어내지 않으며 AI 모델·송신 모듈·클립보드·예약 작업·PC 정보 수집·파일 저장을 호출하지 않는다.

## 기능

- 새로운 `방송 전 공지 초안` 탭에서 운영자가 수동으로 입력한 `YYYY-MM-DD HH:MM`(한국 시간)과 선택적 100자 이내 한 줄 주제로 `공지 초안 수동 생성`을 누를 때만 문구 생성.
- 기존 `offline_settings.validate_settings()`와 `active_persona()`를 재사용하여 저장 설정의 플랫폼 복수 선택·캐릭터·콘텐츠를 반영. 기본 캐릭터 모드가 사용자가 보관해 둔 직접 제작 캐릭터 초안을 노출하지 않도록 처리.
- `@everyone`/`@here`와 URL, 제어 문자·개행·비정상 데이터 거부. 실제 링크는 미설정 안내.
- 시각/주제 입력 변경 및 방송 설정 저장 시 화면의 이전 초안 무효화. 오류 시 이전 미리보기가 남지 않음.
- 생성 결과는 읽기 전용 `tk.Text`에만 표시. **전송·자동 등록·예약·실제 방송 시작 없음**.
- 생성된 문구는 고정 템플릿의 초안이며 사용자 스타일을 따라 자연스러운 LLM 문장을 생성한 것은 아니다. 원본 088의 스타일/변주 기능은 후속 단계.

## 보존 및 승인 대기

원본 기획안·`config/roadmap.json`의 단계 상태는 변경하지 않는다. 원본 084와 사용자 최종 승인 010은 `pending`으로 둔다. **코드 개발 도달 범위만 84/100**이며 제품 완성률이 아니다. 실제 Windows EXE/폰트/장치, 캐릭터 말투 자연스러움, 실제 플랫폼 계정/공지 권한 및 공식 API, 게시 성공/중복/삭제, 실시간 방송 연동, 이용 약관, 사용자 승인 모두 별도 검증 대기.
