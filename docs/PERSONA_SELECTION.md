# 5단계: 캐릭터 기본값 / 직접 만들기 선택형 설정

기본 캐릭터 이름은 **아이스팅**이다. 사용자는 개발 중 사전 확정 없이 Windows 프로그램
'방송 설정' 화면에서 언제든 **기본 캐릭터** 또는 **직접 만들기**를 선택한다.

- 기본 모드: 저장된 사용자 초안과 무관하게 기본 캐릭터 적용. 입력 창은 비활성화한다.
- 직접 만들기: 이름·말투·성격 1~200자 편집 허용. 프로그램의 로컬 설정 파일에만 보관한다.
- 다시 기본 모드로 돌아가도 입력한 초안은 지우지 않고, 직접 만들기로 재선택 가능하다.
- v05에서 이미 캐릭터 항목을 수정한 저장 파일은 최초 읽을 때 직접 만들기로 판단한다.
  수정하지 않은 저장 파일은 기본 캐릭터로 읽는다. **원본 파일은 불필요하게 덮어쓰지 않는다.**
- 실제 선택에 따라 2D 캐릭터 이름이 바뀐다. 로컬 Ollama는 사용자가 직접 요청할 때만
  시스템 지침에 이름·말투·성격을 넣는다. 모의 답변은 원래의 시험 응답 그대로다.
- 캐릭터 설정 저장·선택만으로 네트워크 연결, 음성 복제, 구매, 설치, 방송 송출을 하지 않는다.

공식 100단계 5단계가 구현되었고, 6단계 상세 성격·말투 품질 초안은 미완료다.
Windows EXE 실제 빌드는 사용자의 PC 설치 승인 뒤 별도 검증이 필요하다.
