# AISTING 누적 v44 — 원본 계획 043 음성 자료 품질 검사 (수동 기록)

## 실제 구현된 범위

- `src/ai_broadcaster/voice_quality_review.py`: 42단계 운영자 입력 준비표의 음성 출처/자료별칭/예상 길이와 평가표를 SHA256으로 결합. 실제 음성 파일을 열지 않고 파일별 네 가지 평가 **배경 잡음, 잘림·왜곡, 발화 명료도, 음량 일관성**을 운영자가 **미평가 / 운영자 양호 기재 / 보완 필요**로 수동 기입.
- `음성 품질 수동 검토` GUI 탭: 42단계 저장 준비표 수동 참조 → 항목 선택/평가/미리보기 → 확인 후 로컬 JSON 저장 / 수동 불러오기 / 2회 확인 삭제 / 화면 초기화.
- 준비표나 음성 선택 변경 시 과거 평가를 재사용하지 못함. 저장 시점에 준비표가 변경됐어도 저장 차단. 파일 저장/불러오기/삭제는 명시적인 버튼 동작에만 수행하며 앱 초기화에서 자동 접근하지 않음.
- 항목별 메모는 짧은 한 줄만 허용하고 경로/주소 입력을 억제. 자유 텍스트이므로 개인정보를 완벽히 감지하지 못함. 녹음/동의서/파일명/경로를 기재하지 말 것.
- 저장 파일 `voice_quality_operator_review.json`은 별도 스키마 및 크기 제한, 원자 교체, 심볼릭 링크 경로 거부, 엄격한 형식 검증. 저장 데이터의 `audio_analyzed=false`, `training_authorized=false`, `broadcast_authorized=false`는 절대 자동 승인으로 전환되지 않음.
- 이전 설정/SQLite/권리 기록/음성 자료 준비표, 플랫폼·콘텐츠·캐릭터·목소리·아바타 선택, 원본 기획안 보존.

## 한계 및 미확인

이 기능의 **품질 검사는 운영자가 직접 작성한 관찰 기록**이지 실제 녹음 파일의 소음, 샘플레이트, 잘림, 합성 적합성에 대한 측정이 아니다. 42단계 예상 길이도 실측값이 아니다. 이용 권리·성우 동의·음성 학습 허가·복제/송출 승인/실물 확인은 **완료 처리하지 않는다**.

10단계 사용자 최종 승인, 11단계 이후 사용자 PC 확인, 실제 Windows GUI/EXE, 실제 녹음 자료에 대한 품질 분석과 사용권 확인은 별도 승인/검증 대기. GitHub·인터넷·외부 API·설치·유료 결제·계정 연결·OBS 방송·원격 PC 제어·PC 정보 자동 수집 없음.

다음 원본 로드맵 044 **한국어 음성 합성 환경 구성**: 사용자 PC 설치/환경 조사는 승인 대기, 가능한 순수 오프라인 구성 계획부터 진행.
