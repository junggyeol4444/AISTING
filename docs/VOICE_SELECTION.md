# AISTING 7단계: 사용할 목소리 확보 방식 — PC 안에서 선택

프로그램은 사전에 특정 목소리를 고르라고 요구하지 않습니다. 방송 설정에서 언제든 '미정',
'Windows 무료 음성', '내 목소리 (추후 직접 녹음)', '동의받은 목소리 (추후 확보)',
'라이선스 확보 목소리 (추후 확보)'를 선택할 수 있습니다.

## 현재 실제 동작
- Windows PC에 이미 있는 `System.Speech` 한국어 음성을 사용자가 직접 찾고 미리 듣기.
- PC의 로컬 설정 파일에 이름, 재생 속도(-4~4), 음량(0~100) 저장.
- 다음 실행에서 그 음성이 없으면 임의로 다른 목소리를 선택하지 않고 안내.
- 응답 자동 읽기는 이전처럼 **기본 꺼짐**이며, 사용자가 활성화해야 시작.
- 방송 플랫폼, 유료 TTS, 개인 음성 녹음, 타인의 음성 복제는 실행하지 않음.

## 미래 계획만 기록되는 방식
- 내 목소리: 본인이 직접 녹음·학습을 승인하고 PC 준비 여부 확인 후 별도 구현.
- 동의받은 목소리: 제공자의 구체적인 사용 동의와 권한 확인 전에는 학습 금지.
- 라이선스 확보 목소리: 사용 목적에 맞는 정당한 권리 확보 전에는 학습 금지.
- 해당 옵션을 저장하는 것은 동의를 확보했다고 인증하거나 복제를 허가하는 행위가 아님.

모든 기능은 로컬 Windows 앱에서 동작하도록 설계합니다. GitHub, 자동 커밋/배포,
원격 서버, 요금 결제, PC 자동 설치, 무단 녹음/복제, 실제 방송 시작은 없음.
