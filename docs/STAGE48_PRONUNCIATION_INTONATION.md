# v48 / 원본 047 ‘발음 및 억양 확인’ — 오프라인 수동 평가 준비

## 구현 근거 및 범위

원본 100단계 표 047은 **발음 및 억양 확인**입니다. 운영자가 무엇이 사람처럼 자연스러운지 결정한다는 원본 기획안 방침을 유지합니다. 이 개발본은 **음성 품질 자동 판정기나 실제 재생 기능이 아닙니다.** 41~46 단계의 권리 체크·자료 계획·품질 점검·음성 환경·출력 경로는 이미 별도로 존재하므로 중복 구현하지 않았습니다.

- `src/ai_broadcaster/pronunciation_review.py`: 발음/억양 운영자 기재용 `PronunciationReview`·`PronunciationItem`, 최대 12개의 한국어 시험 문장(각 160자), 문장 순서 및 중복 보존. 초기값은 모두 `미평가`; 운영자가 문장별로 `운영자가 적절하다고 기재` 또는 `수정 필요`를 고르고 메모할 수 있습니다.
- 기존 선택형 음성 확보 방식 및 Windows 음성 프로필을 검사해 **목소리 출처·음성 이름·속도·음량**이 바뀌었을 때 기록 재사용을 거부합니다. Windows 음성 출처이면 사용자가 선택한 정확한 이름이 필요하고, **설치된 음성 자동 조회는 수행하지 않습니다.** 다른 음성 출처는 아직 실제 음성과 연결되지 않았음을 분명히 합니다.
- `desktop.py`의 `발음·억양 수동 검토` 탭: 사용자가 평가표 작성/미리보기/문장별 평가 반영/확인 후 저장/수동 불러오기/2회 확인 삭제. 입력 문장이나 음성 선택·속도·음량을 변경하면 **기존 평가표를 화면에서 즉시 무효화**합니다.
- 별도 사용자 로컬 파일 `pronunciation_intonation_operator_notes.json`에 저장하며 기존 `settings.json`, SQLite 기억, 기획안은 변경하지 않습니다. 파일은 사전 확인 없이는 생성·변경하지 않습니다. 저장은 임시 파일 fsync 후 원자적 교체, 저장량 상한과 JSON 스키마 검사, 링크/정션 경로 차단을 적용합니다.
- 저장된 평가 기록의 `audio_played`, `audio_analyzed`, `training_authorized`, `broadcast_authorized`는 모두 반드시 `false`입니다. 체크가 양호여도 실제 청취 여부·발음·억양의 객관적 품질, 음성 사용권, 학습이나 방송 허가를 뜻하지 않습니다.
- 입력 문자열은 경로·URL·연락처로 보이는 내용 및 제어문자를 받지 않습니다. 개인정보/실제 음성 파일/녹음 내용을 수집하지 않습니다.
