# AI 방송인 — 100단계 개발 로드맵

사용자가 요청한 100개 단계를 하나씩 구현·검증한다. 단계 통과의 기준은 실행 가능한 결과와 운영자 확인이다.

**사용자의 최신 명시 지시:** 003은 특정 플랫폼을 미리 하나 확정하는 단계가 아니라,
프로그램에서 치지직·유튜브·트위치를 사용 중에 직접 선택·해제할 수 있게 만드는 단계다.
이 방식은 이미 확정됐으므로 운영자에게 사전 선택을 다시 요구하지 않는다.
계정 로그인·실시간 채팅 수집·실제 방송 송출은 별도 미구현 단계로 구분한다.
방송 콘텐츠, 캐릭터 기본값/직접 입력, 목소리, 아바타도 프로그램 사용 중 선택하는
설계이며 사용자에게 사전 확정을 요구해 개발을 중단시키지 않는다.
004는 4개 옵션 저장·변경·GUI 확인 및 선택한 콘텐츠의 로컬 AI 지침 반영을
별도 테스트한 뒤 완료 처리했다. 콘텐츠를 선택한다고 실제 게임 조작이나 방송이 시작되지는 않는다.

005는 기본 캐릭터와 운영자가 직접 작성하는 캐릭터를 런타임에 선택·변경할 수 있게
구현·검증했다. 특정 성격·말투 확정은 요구하지 않으며 006 세부 성격·말투 초안은 별도 단계다.

006은 사용자가 특정 성격과 말투를 개발 전에 결정해야 한다는 뜻이 아니다.
기본값과 자유 편집 가능한 초안을 제공하고 사용자가 선택해 적용·수정한다.
AI 지침 미리보기는 로컬 문자열로만 만들며 실제 모델의 답변 결과를 검증한 것은 아니다.

007은 사용자가 특정 목소리를 사전에 확정하는 단계가 아니다. 프로그램 안에서 무료 Windows 기본 음성이나
향후 본인·동의·라이선스 확보 방식 중 선택하고 바꿀 수 있다. 목소리 학습과 복제는 미구현이며
권리·동의·사용자 승인 확인을 거쳐야 한다. 선택한 Windows 시스템 음성·속도·음량을 PC에 저장하고
목소리가 설치되지 않은 경우 다른 음성으로 임의 대체하지 않는다.

008도 2D·3D 중 하나를 개발 시작 전에 확정하는 조건이 아니다.
Windows 프로그램에서 **미정 / 2D / 3D**를 자유롭게 선택·저장하고,
3D에는 실제 VRM 렌더러가 없다는 안내를 표시한다. 2D 샘플을 3D처럼 대체하지 않는다.
정식 아바타 모델 도입·3D 렌더링·실제 립싱크 구현은 후속 단계다.

009는 운영 장소를 사용자가 이미 확정한 **Windows PC**로 유지하고, 실행 과정에 GitHub·클라우드가
불필요한 구조를 코드와 화면에서 확인하는 단계다. 무료 모의 응답과 SQLite 기억은 PC 내부에서 처리하며
로컬 Ollama는 운영자가 직접 선택한 경우에만 `127.0.0.1`에 연결한다.
PC 저장 폴더 진단은 사용자 버튼 클릭으로만 수행하며 PC 사양 조사는 하지 않는다.
실제 Windows EXE 실행과 통합 방송은 아직 검증하지 않았다.

010은 사용자 스스로 전체 개발 기준을 확인하는 단계다. 검토 UI 구현만으로 자동 승인 처리하지 않는다.

## v15 개발 기록 (공식 단계 승인과 별도)

014 `필요한 프로그램과 비용 일괄 안내`의 **오프라인 참고 화면**을 구현했습니다.
`프로그램·비용 안내` 탭에서 현재 소스와 미래 후보를 나눠 프로그램/비용 17개 항목을 한 번에 표시합니다.
PC 설치 상태와 현재 판매가를 조회하지 않고, 총액을 임의로 계산하지 않습니다.
운영자의 실제 검토·승인 전에는 014를 완료로 표시하지 않습니다. 015 설치 승인은 별도 보류합니다.
자세한 설명은 `docs/PROGRAM_COST_GUIDE.md`에 있습니다.

## v16 개발 기록 (공식 단계 승인과 별도)

015 `프로그램 설치 여부 승인`은 **사용자 승인 대기**로 유지합니다. 승인 없이 프로그램을 설치하지 않았습니다.
016 `개발용 폴더와 작업 공간 구성`은 사용자 선택 경로 미리보기, 확인 후 수동 폴더 생성, 기존 파일 충돌·식별 파일·심볼릭 링크 보호, 반복 실행 시 기존 파일 보존 기능을 구현했습니다. 실제 사용자 PC에 폴더를 만들거나 승인받은 것은 아니므로 016은 미완료 상태입니다.
`docs/WORKSPACE_SETUP.md`에 사용법·제약·검증 범위를 기록했습니다. 010~016은 사용자 승인/PC 실기기 검증 대기, 공식 완료 9/100 유지. 승인 대기와 관계없이 후속 단계 개발을 계속합니다.

## v17 개발 메모 — 017 기본 실행 환경 설정

017의 사용자 PC 실행 환경 최종 확인은 미완료 상태로 유지한다. `runtime_profile.py`와 **기본 실행 환경** 탭에서 모의 응답 또는 운영자 수동 로컬 Ollama 모드를 선택·검증·기록·적용·삭제하는 기능을 준비했다. 앱 시작/프로필 저장 시 모델 자동 연결이나 방송 시작을 하지 않으며 기존 사용자 선택과 SQLite 기억은 변경하지 않는다. 010/015 승인이 없다는 이유로 개발을 중단하지 않는다. `docs/RUNTIME_PROFILE.md` 참고.


## v18 개발 메모 — 018 기획안과 설정 파일 보관

- **코드 구현/가상 GUI 검증만 진행**: 사용자가 선택·확인할 때 원본 기획안, 요구사항, 로드맵 및 선택형 로컬 설정 사본을 새 ZIP으로 보관하고 SHA256을 검사.
